### 2.1 F1 · Prompt 越狱（5/5）

| 断言 | 实测 |

| 拒绝收口 | ✅ 5/5 REFUSE，零引用 |
| 拒绝理由分布 | HIGH_RISK_TOPIC ×4、OFF_TOPIC ×1 |

### 2.2 F2 · 畸变脏参数（10/10）

| 用例 | 预期 | 实测 |
| :--- | :--- | :--- |

### 2.3 F3 · 下游故障注入（6/6，真杀进程）

这是本套件唯一**破坏性**注入组：真实 kill 8310 检索内核，断言降级契约，再验证自动恢复：

### 3.2 亮点样本

- **跨版本冲突全对**：QA-013（VPN 806 错误 → 现行 v1.0 规范推荐 SSL VPN）命中 3/3 关键词；QA-015（DNS 消歧）命中 3/3——废止卡被元数据物理屏蔽，答案引用的均为现行版。

- **事实关键词可溯**：12 道常规题答案均命中金标关键词（如 mdsched/MemTest86、Print Spooler、onedrive.exe /reset），引用可回溯到具体知识卡。

## 四、测试驱动出的产品修复（注入/盲测的价值证明）

盲测与注入暴露的 3 个真实缺陷均已修复并回归验证——这正是混沌测试的意义：**不是证明系统没问题，而是把问题找出来**。

### 4.1 领域判定词面误杀（2 处，已修复）

| 缺陷 | 现象 | 根因 | 修复 |
| :--- | :--- | :--- | :--- |
| BUG-1 | 「移动硬盘提示需要格式化」（QA-008）被拒答 | 题面含「格式化」命中高风险动作词表 → 误判 HIGH_RISK | `rag-service` DomainClassifier 增加「提示/显示…格式化」故障描述豁免；「帮我格式化硬盘」仍正确拦截 |
| BUG-2 | 「出差在酒店连 VPN 报错 806」（QA-013）被拒答 | 「酒店」命中领域外词表 → 误判 OFF_TOPIC | 同上，增加「酒店/出差/在家 + VPN/网络」连网场景豁免；「出差订酒店」仍判 OFF_TOPIC |
| BUG-3 | 「文件被 Shift+Delete 删除怎么找回」（QA-011）被拒答 | 语义分类器把「描述数据丢失现象」误判为「数据丢失恢复请求」 | `consultation-service` 分类提示词补「描述故障现象 ≠ 执行危险动作」区分；「帮我恢复生产数据库」仍拦截 |

### 4.2 已知限制（如实上报，均有降级兜底，不构成阻断）

| # | 限制 | 影响 | 建议 |
| :--- | :--- | :--- | :--- |
| 1 | kspmas 中继 `/rerank` 按请求随机分流两种协议互斥的后端，且坏窗口期占比时段性升高 | rerank 精排间歇不可用（自动降级启发式打分，检索可用性不受影响） | 已在客户端实现自检重试（8 次）+ 扁平/嵌套协议交替自适应；根治需网关侧统一后端 |
| 2 | topK 参数契约未定义值域，0/-1/超大值被松散截断 | 无安全影响，仅契约不严谨 | `RagRetrievalRequest` 增加 `@Min(1)/@Max(50)` 校验 |
| 3 | 超短查询（如 4 字「电脑蓝屏」）召回弱，返回空结果触发 LOW_CONFIDENCE 拒答 | 属「宁拒不编」预期行为；完整问句均正常命中 | 可选优化：短查询同义词扩展 |
| 4 | 上游偶发 MODEL_UNAVAILABLE（限流/分流波动） | 用户侧收到「系统繁忙」类拒答，无错误内容外泄 | 已有客户端退避重试缓解；建议关注 kspmas 配额 |

### 5.3 测试方法说明（供答辩问答）

- **为什么是真机注入而不是 Mock**：Mock 只能证明「假设下游挂了代码逻辑对」，真机注入额外证明了「降级路径上的每个真实组件（网关路由、超时预算、异常映射、落库）都按契约工作」——F3 实测中 8302 在 8310 宕机时返回的是 200+空结果而非 5xx，这条只有真机才能验证。
- **为什么盲测题源复用金标集**：金标 20 题已带标准答案、引用卡 ID 与关键词，判定可量化、可复现；「恶意注入」题型天然属于故障注入域，由 F1/F4 覆盖避免重复建设。
- **重试会不会掩盖真实缺陷**：不会。重试仅针对两类已定位的环境性失败（上游 MODEL_UNAVAILABLE、检索降级窗口的间歇性空召回），且越界陷阱题（期望拒答）不参与检索性重试，防止「把拒答重试成回答」；确定性失败（领域误判）在重试下依然稳定复现，从而被识别并修复。

## 六、结论

1. **四类混沌故障注入 28/28 通过**：越狱全拦、脏参数零 5xx、下游宕机优雅降级且可自动恢复、注入串与越权全防——AI 客服链路在故障态下的行为符合 RD-006 降级契约与安全红线。
2. **盲测四题型 20/20 = 100%**：生僻题可答可溯、跨版本冲突取现行版、越界陷阱宁拒不编、恶意注入由注入套件覆盖——达到 Day20「四题型 100% 应对」验收口径。
3. **测试产出真实价值**：暴露并修复 3 个领域判定缺陷（均有守卫回归证明安全线未放松），沉淀 2 个可复用测试套件与 4 项已知限制的透明记录。
4. **遗留建议**：topK 值域校验（低优）、kspmas 网关后端统一（外部协调）、短查询同义扩展（可选优化）。
