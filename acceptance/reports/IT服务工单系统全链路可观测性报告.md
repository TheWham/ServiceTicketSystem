## 二、能力一：每次回答全过程留痕

每一次用户提问，平台自动记录一条完整链路：

```
提问 → 意图/风险判定 → AI 推理 → 知识检索（含评分）→ 工具调用 → 回答 + 引用
```

**实测数据**：
- 148 次问答全部有完整追踪链，其中 137 次携带知识材料、133 次最终回答附知识引用；
- 每步的输入摘要（SHA-256 哈希留痕，**原文不落追踪平台**）、输出、置信度、使用的知识版本 ID 全部记录；
- 平均置信度 0.85（区间 0–0.99），低置信回答自动走拒答/澄清通道，不硬答。

**客户价值**：回答可解释、可审计——每条答案为什么这样生成、依据哪条知识，数秒内可定位。追踪数据脱敏设计（问题原文仅存哈希），**观测平台本身也不成为泄密面**。
