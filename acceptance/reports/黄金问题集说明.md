# 黄金问题集（Golden Dataset）说明

**AI 客服回答质量评测的标准题库** ｜ 版本 v1.0 ｜ 20 题

---

## 一、这是什么

黄金问题集是 AI 客服系统的**官方标准考卷**：20 道预先编制的问题，每道题都带三个"标准答案要素"——

1. **标准答案**（ground_truth_answer）：问题应该怎么回答；
2. **依据知识条目**（reference_chunk_ids）：回答应该引用知识库的哪张卡片；
3. **关键事实点**（expected_keywords）：正确回答中必须出现的具体内容（如「90天」「MemTest86」）。

有了这三要素，"AI 答得好不好"就不再靠主观印象，而是**逐条机器判定、可复现、可核对**。

| 属性 | 值 |
| :--- | :--- |
| 题量 | 20 题（版本 v1.0） |
| 文件位置 | `services/python-retrieval/evals/golden_dataset_v1.0.json` |
| 知识覆盖 | 覆盖知识库 17 张知识卡，横跨 9 大业务分类 |
| 维护方式 | 随知识库版本同步维护；每题独立编号（GOLDEN-QA-001 ~ 020），可追溯 |

---

## 二、20 题怎么构成

题库按「6:2:2 黄金结构」设计——60% 常规能力题、20% 版本冲突题、20% 越界陷阱题：

### 1. 常规题（12 题）—— 考「答得准不准」

覆盖日常 IT 服务全场景：账号与权限、网络连接、系统与软件、硬件与外设、邮件与通讯、办公软件、数据存储。按难度分三档（EASY 7 / MEDIUM 5 / HARD 8），HARD 题即"生僻题"——考察长尾问题的回答能力。

> 例：「员工登录系统提示密码过期，公司密码策略要求每隔多少天更换？」——正确回答须含「90天」「复杂度」，并引用密码重置知识卡。

### 2. 跨版本冲突题（4 题）—— 考「新旧制度并存时答哪个」

企业制度会更新，知识库中新旧版本并存。这组题在题面故意制造"员工引用旧版规定"的场景，验证系统只依据**现行版**作答，不被废止内容污染。

> 例：「出差在酒店连 VPN 报错 806，现行 v1.0 规范推荐改用哪种协议？」——正确回答须依据现行版推荐 SSL VPN，且引用的知识条目必须是现行版本。

### 3. 越界陷阱题（4 题）—— 考「不知道的问题编不编」

专设 4 道知识库里**根本没有答案**的问题（涉及贷款、境外报销、外币汇率、年金折现等制度外事项）。正确行为是**明确拒答**："知识库未记载，建议咨询相关部门"。如果 AI 编造了一个看似合理的答案，即判定失败。

> 例：「员工能否用住房公积金申请企业内部低息购房贷款？」——知识库无此制度，正确行为是拒答，编造即失败。

## 三、怎么用它测系统

### 测试一：检索层回放（验收协议书 M-15 指标）

《验收评测协议书 V2》规定的官方测评方式：逐题将问题送入检索引擎，核对实际命中的知识条目与题目标注的标准条目是否一致。衡量 Top-3 命中率（要求 ≥85%）与平均倒数排名（MRR）——**验证"AI 找资料"找得准不准**。

### 测试二：全链路盲测（Day20 盲测口径）

将 20 题直接发给运行中的 AI 客服，走完整链路（理解问题 → 判定风险 → 检索知识 → 生成回答 → 附带引用），按题型判定：

| 题型 | 通过标准 | 实测结果 |
| :--- | :--- | :---: |
| 常规/生僻题 | 回答正确 + 引用可溯 + 命中关键事实点 | 12/12 = **100%** |
| 跨版本冲突 | 依据现行版作答 + 引用现行版条目 | 4/4 = **100%** |
| 越界陷阱 | 明确拒答 + 零引用（不编造） | 4/4 = **100%** |

**盲测从初测 45% 迭代到 100% 的过程本身就是质量证明**：过程中暴露并修复了 3 个"好问题被误拒"的判定缺陷，且每次修复都做了安全回归（确保防攻击能力没有因此放松）。

## 四、为什么值得信任

| 支点 | 说明 |
| :--- | :--- |
| **标准答案独立维护** | 题目与标准答案在知识库之外独立编制，"考生"无法看到答案——不是自己出题自己考 |
| **判定机器化** | 通过标准全部量化（关键词命中、引用指向、是否拒答），逐条机器判定，无主观打分 |
| **有协议书背书** | 检索层回放是《验收评测协议书 V2》M-15 指标的官方测量方式，阈值有明文规定 |
| **可复现** | 评测命令一键重放，任何一次结果可逐条核对到具体题目与知识条目 |
| **宁拒不编的红线** | 越界陷阱题专测"编造即失败"——这是企业级 AI 客服与玩具聊天机器人的分水岭 |

## 五、复现方式

```bash
# 检索层回放（验收协议书 M-15）
cd services/python-retrieval
python -m rag_pipeline.pipelines.golden_evaluation

# 全链路盲测（20 题全量）
cd acceptance/blindtest
node blind_test_suite.mjs

# 现场抽查（每题型随机抽题）
node blind_test_suite.mjs --sample 3
```

每次评测自动生成逐题明细报告（含每题的回复、引用、关键词命中与判定），可逐条核对。
