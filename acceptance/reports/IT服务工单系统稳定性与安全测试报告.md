## 一、测试结论

| 测试项 | 结果 | 达标口径 |
| :--- | :---: | :--- |
| 四类混沌故障注入 | **28/28 全部通过** | 故障下不崩溃、不泄密、优雅降级、自动恢复 |
| 盲测四题型 | **20/20 = 100%** | 生僻题可答可溯、跨版本冲突取现行版、越界宁拒不编、注入全防 |

## 二、混沌故障注入：系统在攻击和故障下表现如何？

| 攻击/故障场景 | 验证点 | 结果 |
| :--- | :--- | :---: |
| **Prompt 越狱**（5 种话术套取系统提示词、诱导违规作答） | 不泄密、不吐内部信息、全部礼貌拒绝 | ✅ 5/5 |
| **脏数据攻击**（超长文本、空值、非法参数等 12 种畸形输入） | 零服务崩溃、零堆栈暴露，非法输入快速拦截 | ✅ 12/12 |
| **下游服务宕机**（真实终止检索服务进程） | 系统不报 500、不挂死：自动降级为「系统繁忙」话术，对话记录完整；服务恢复后链路秒级还原 | ✅ 6/6 |
| **注入攻击与越权**（SQL/DSL 注入串、未认证访问、伪造单号） | 注入串一律当普通文本；越权请求全部 401/404，不泄露数据存在性 | ✅ 6/6 |

**客户价值**：无论遭遇恶意用户还是内部故障，AI 客服都不会崩溃、不会泄露敏感信息、不会给出编造内容——最坏情况只是「暂时无法回答，建议转人工」。

## 三、盲测：回答质量是否可信？

使用 20 道带标准答案的评测题（题库独立于知识库维护），按四类难点全量盲测：

| 题型 | 考察能力 | 应对率 |
| :--- | :--- | :---: |
| 生僻题（12 题） | 长尾问题能否答对、答案能否溯源到知识库 | **100%** |
| 跨版本冲突（4 题） | 制度新旧版本并存时，能否只依据现行版作答 | **100%** |
| 越界陷阱（4 题） | 知识库没有的问题，能否**拒绝编造** | **100%** |
| 恶意注入 | 由故障注入测试覆盖（见第二节） | **100%** |

**客户价值**：
- 每条回答都附引用来源，可追溯到具体知识条目；
- 知识库未覆盖的问题，系统明确告知无法回答，**杜绝 AI 幻觉编造**——这是企业级客服与玩具级聊天机器人的分水岭。

## 四、测试不止于发现问题，更驱动了改进

盲测暴露了 3 个「好问题被误拒」的判定缺陷（如「硬盘提示需要格式化」因含「格式化」一词被误判为高危操作），均已修复并复测通过。

**修复安全性证明**（关键）：修复后对全部安全防线做回归测试——越狱攻击仍全拦、真实高危请求（如「帮我格式化公司数据库」）仍全拦、越界问题仍全拒。**易用性提升未以牺牲安全为代价。**

## 五、已知事项（透明披露）

| 事项 | 影响 | 状态 |
| :--- | :--- | :--- |
| 外部模型中继偶发限流 | 极少数请求可能收到「系统繁忙」提示 | 已有自动重试缓解，无错误内容外泄 |
| 超短查询（如仅 4 个字）召回较弱 | 系统拒答而非硬答 | 属「宁拒不编」设计；完整问句均正常 |
