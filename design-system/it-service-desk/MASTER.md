# IT Service Desk · 已实施设计规范

2026-10-08 二次修订。用户要求在现有前端上加强未来科技感，使用 ui-ux-pro-max 完善。结构与基础组件规范对应 `service-desk.css`；当前视觉覆盖层以 `frontend/src/styles/future-desk.css` 为准。

## 风格

深空蓝黑 + 电光青，浅色版本为银白冰蓝。导航和登录品牌区使用低亮度光线、细网格、青蓝色边缘；内容保持不透明、清晰可读。英文小标题与编号采用本地等宽字体，中文保留系统无衬线字体；不加载在线字体。

## 布局和组件

- 桌面导航 224px，中等桌面 196px；可收起为 76px；手机使用带焦点管理的 Element Plus Drawer。
- 桌面顶栏 72px，手机 64px；页面间距 32/24/16px；最大内容宽度 1440px。
- 主标题 22–28px；区域标题 16–20px；正文和表格 14px；手机输入框 16px。
- 工作区卡片圆角 12px，控件 8px；间距 4/8/12/16/24/32px。导航选中态用青色细边、侧光线及轻渐变共同标识。
- SVG 图标复用 Element Plus。纯装饰图标从可访问树隐藏，独立按钮具备名称。
- 登录页使用共享 `OrbitalCore.vue` SVG 轨道式 AI 图形，配合咨询/协同/解决服务流程。图形仅为装饰，不承载真实运行状态。
- 咨询页主会话+右侧指南；小屏保留会话与主要入口。历史阅读时提示新消息，用户可主动回到底部。
- 工单页面区分问题信息、位置/联系方式/资产、附件；输入和状态错误就近展示。
- 工程师页按真实状态分组，已结束视图包含完成、取消和关闭，文字分别标注。
- 知识库保留真实文档处理/审核能力；管理统计明确当前页或已加载范围，不伪造全量数据。

## 导航契约

`navigation.js` 为菜单、标签与主页的共享来源；服务端与路由守卫负责权限。

- 员工：`/consultation`、`/employee?tab=create|list`。
- 工程师：`/engineer` 及 `?view=pool|tasks|completed|consultations`。
- 平台管理员：`/supervisor`、`/accounts`。
- 知识库管理员：`/knowledge-admin?tab=ingest|lifecycle`；KB_ADMIN 旧权限保持兼容，不新增后端权限。

## 交互与验收

所有交互支持可见键盘焦点；手机导航关闭恢复焦点；弹窗不超出屏宽；列表空态和错误态分离；输入法 Enter 不发送未确认文字。保留 reduced-motion。统计数字仅使用真实接口数据。

本轮检索命中 Glassmorphism 与 HUD / Sci-Fi FUI：采用受控半透明导航、细线图形、背景网格；不采用闪烁、故障特效、正文光晕或大面积表格模糊。顶部导航 blur 14px，手机关闭。页面/轨道仅入场一次，reduced-motion 关闭动画，forced-colors 恢复实色标题。保留用户已有明暗偏好。
