# 2024年Q1销售一部华东大区差旅合规性审计通报表

## 1. 适用范围与生效准则

本通报表由财务审计二处于2024年4月10日制表，适用于2024年Q1销售一部华东大区差旅报销合规性审计结果的归档与后续系统录入核验。系统录入时必须严格区分2024年3月1日生效节点：发票日期在2024年3月1日之前，严格执行旧版600元上限标准；2024年3月1日之后，一律执行新版800元分级标准。本通报表本身不直接发布制度替代文件。

## 3. 冲突与历史变更裁决说明

### 3.1 版本冲突特别裁决条款
> 凡涉及2024年3月1日之后发生的业务，系统录入报销须按本通报表口径执行节点切割：发票日期在2024年3月1日之前，严格执行旧版600元上限标准；2024年3月1日之后，执行新版800元分级标准。夜间加班打车报销按新规以21:00后为允许节点，本表中HK8110的21:15发票审批通过。

> 原表中HK7991王大明行存在数据内部不一致：报销金额为1800.00元，事由为“北京出差2天住宿”，违规与特批情况说明为“按800元/天填报，但新规3月才生效，旧规上限600元，多报400元已被追回”。按2天×800元/天应为1600元，按2天×旧规600元/天应为1200元，差额为400元；表内报销金额1800元与该说明及2天口径不一致。本卡保留原值，不作修正或反推。
