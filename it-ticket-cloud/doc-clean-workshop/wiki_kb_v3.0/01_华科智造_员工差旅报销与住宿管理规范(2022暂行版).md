# 华科智造员工差旅报销与商务住宿管理规范（2022年暂行版）（已废止，仅备查）

## 1. 适用范围与生效准则

本制度自 2022 年 1 月 1 日起生效，适用于集团总部各部门及旗下控股子公司全体全职员工。住宿费用实行单一上限封顶报销，不区分城市级别，超出部分自理。

## 2. 标准明细表（实报实销上限 / 业务数据，与源文同构）

### 2.1 交通出行标准

| 出行方式 | 适用职级 | 可乘坐标准 |
| :--- | :--- | :--- |
| 飞机 | 总监级（含）以上 | 经济舱 |
| 飞机 | 副总裁及以上 | 经审批可乘坐商务舱 |
| 高铁 | 普通员工及经理级 | 一律乘坐二等座 |
| 高铁 | 总监级及以上 | 可乘坐一等座 |

### 2.2 住宿标准明细与报销上限

| 职级/人员类别 | 住宿费报销上限 |
| :--- | :--- |
| 总监级及以上管理人员 | 600 元/天 |
| 部门经理与资深专家（P6-P7） | 450 元/天 |
| 普通员工（P4-P5） | 350 元/天 |

注：住宿发票必须开具增值税专用发票，连同行程单一同提交财务系统审批。

### 2.3 差旅市内交通与夜间加班打车

| 场景 | 规则 |
| :--- | :--- |
| 出差期间市内交通 | 优先乘坐公共交通（地铁、公交） |
| 夜间加班打车（出差期间，紧急项目） | 当日工作时间超过 22:30 且公共交通停运的，可凭有效网约车发票实报实销往返酒店的打车费用；早于 22:30 之前的打车支出一律不予报销 |

## 3. 冲突与历史变更裁决说明

### 3.1 版本冲突特别裁决条款

> 本卡条款（第五条住宿标准、第七条夜间加班打车报销限制）自 2024-03-01 起被 HK-2024-FIN-088 废止。凡涉及 2024-03-01 之后发生的差旅住宿报销与夜间交通补贴业务，一律以 HK-2024-FIN-088 为准，不再沿用本卡旧版标准。

### 3.2 历史条款对比

| 变更事项 | 本卡（2022年暂行版，旧规） | HK-2024-FIN-088（2024年03月补充通知，新规） |
| :--- | :--- | :--- |
| 住宿报销上限：一线城市（北京市、上海市、广州市、深圳市） | 总监级及以上 600 元/天；部门经理与资深专家（P6-P7）450 元/天；普通员工（P4-P5）350 元/天；单一上限，不区分城市级别 | 总监级及以上 800 元/天；部门经理与专家（P6-P7）550 元/天；普通员工（P4-P5）450 元/天 |
| 住宿报销上限：二线省会城市 | 同上，不区分城市级别 | 总监级及以上 600 元/天；部门经理与专家 420 元/天；普通员工 350 元/天 |
| 住宿报销上限：三线及其他地级市 | 同上，不区分城市级别 | 全员在二线标准基础上统一顺减 50 元/天执行 |
| 夜间加班打车报销门槛 | 当日工作时间超过 22:30 且公共交通停运，可凭有效网约车发票实报实销往返酒店的打车费用；早于 22:30 之前不予报销 | 21:00（含）之后结束工作返回住处或酒店的，无需特殊审批，凭行程发票即可全额实报实销网约车费 |

### 3.3 数据质量说明

> 本卡原文第三条“总监级（含）以上可乘坐经济舱”与“副总裁及以上经审批可乘坐商务舱”在职级边界上存在表述重叠，本卡保留原值，不作修正或推断。
