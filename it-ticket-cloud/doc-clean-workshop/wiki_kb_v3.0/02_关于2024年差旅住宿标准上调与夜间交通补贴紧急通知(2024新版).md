# 关于调整差旅住宿标准及优化夜间交通补贴政策的紧急补充通知（2024年03月）

> 发文编号：HK-2024-FIN-088　签发人：李敏　发布单位：华科智造科技集团财务共享中心　成文日期：2024年02月28日

## 1. 适用范围与生效准则

本补充通知自 2024 年 3 月 1 日零时起生效，适用于集团各事业部、研发中心、区域营销中心。原《华科智造员工差旅报销与商务住宿管理规范（2022年暂行版）》第五条（住宿单一上限 600 元标准）及第七条（22:30 打车限制）自该时点起废止，一律按本补充通知规定执行。

## 2. 标准明细表

### 2.1 最新城市分级住宿报销上限（自 2024 年 3 月 1 日起执行）

| 城市级别 | 适用职级 | 住宿报销上限 |
| :--- | :--- | :--- |
| 一线城市（限北京市、上海市、广州市、深圳市） | 总监级及以上 | 800 元/天 |
| 一线城市（限北京市、上海市、广州市、深圳市） | 部门经理与专家（P6-P7） | 550 元/天 |
| 一线城市（限北京市、上海市、广州市、深圳市） | 普通员工（P4-P5） | 450 元/天 |
| 二线省会城市（如武汉市、成都市、杭州市、西安市等） | 总监级及以上 | 600 元/天 |
| 二线省会城市（如武汉市、成都市、杭州市、西安市等） | 部门经理与专家 | 420 元/天 |
| 二线省会城市（如武汉市、成都市、杭州市、西安市等） | 普通员工 | 350 元/天 |
| 三线及其他地级市 | 全员 | 在二线标准基础上统一顺减 50 元/天执行 |

### 2.2 夜间加班交通打车报销政策

| 项目 | 报销规则 |
| :--- | :--- |
| 触发门槛 | 由原 22:30 提前至 21:00 |
| 适用条件 | 员工因业务需要异地出差或加班，凡在 21:00（含）之后结束工作返回住处或酒店 |
| 审批要求 | 无需特殊审批 |
| 报销方式 | 凭行程发票即可全额实报实销网约车费 |

## 3. 冲突与历史变更裁决说明

### 3.1 版本冲突特别裁决条款

> 凡涉及 2024-03-01 之后发生的业务，一律以本规定为准，不再沿用旧版标准。财务系统一律按本通知新规进行机审拦截，旧规不再适用。

### 3.2 历史条款对比

| 项目 | 原2022暂行版条款 | 本补充通知（2024-03-01 起） |
| :--- | :--- | :--- |
| 住宿报销上限 | 单一上限封顶，不区分城市级别：总监级及以上 600 元/天；部门经理与资深专家（P6-P7）450 元/天；普通员工（P4-P5）350 元/天 | 一线城市：总监级及以上 800 元/天，部门经理与专家（P6-P7）550 元/天，普通员工（P4-P5）450 元/天；二线省会城市：600/420/350 元/天；三线及其他地级市在二线标准基础上统一顺减 50 元/天 |
| 夜间加班打车 | 当日工作时间超过 22:30 且公共交通停运的，可凭有效网约车发票实报实销往返酒店打车费用；早于 22:30 不予报销 | 21:00（含）之后结束工作返回住处或酒店的，无需特殊审批，凭行程发票即可全额实报实销网约车费 |

### 3.3 数据质量说明

- 原文第三部分使用“即日起”，与第一、二部分及第四部分“自 2024 年 3 月 1 日起执行”的生效口径存在表述不一致。本卡保留原文表述，不推定 2024-02-28 至 2024-02-29 期间的报销适用规则。
- 三线及其他地级市仅给出“在二线标准基础上统一顺减 50 元/天执行”的规则，未逐级列明各职级具体金额；本卡保留原规则，未作计算展开。
