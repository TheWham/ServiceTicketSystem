# 配置管理说明（本地 profile + Nacos 双方案）

## 当前方案：本地 profile 为主（推荐现阶段用）

每个服务目录下有三份配置：

| 文件 | 作用 |
|---|---|
| `application.yml` | 启动项（端口/服务名/Nacos地址/profile开关），不含业务配置 |
| `application-dev.yml` | **测试环境完整业务配置**（默认加载） |
| `application-prod.yml` | **生产环境完整业务配置**（敏感项走环境变量） |

### 启动方式

```bash
# 本地开发（默认 dev，等价于 --spring.profiles.active=dev）
java -jar gateway/target/it-ticket-gateway-1.0.0.jar

# 生产环境
java -jar gateway/target/it-ticket-gateway-1.0.0.jar --spring.profiles.active=prod
# 或环境变量：SPRING_PROFILES_ACTIVE=prod
```

### dev 与 prod 的差异

| 项 | dev（测试） | prod（生产） |
|---|---|---|
| 数据库密码 | **必须注入 MYSQL_PASSWORD** | **必须注入环境变量**，无默认值 |
| JWT 密钥 | 有默认值（dev 弱密钥） | **必须注入 JWT_SECRET** |
| CORS | 放开 `*` | 收紧为 `${CORS_ORIGINS}` 具体域名 |
| 日志级别 | info + mapper debug | warn |

## 后期方案：Nacos 下发（上服务器时启用）

本地 profile 已能满足单机/联调。上服务器后要「改配置不重启」，再启用 Nacos：

```bash
# 启用 Nacos 配置中心（覆盖本地 profile）
NACOS_CONFIG_ENABLED=true java -jar gateway/target/...jar --spring.profiles.active=prod
```

- `NACOS_CONFIG_ENABLED=true` 时，服务从 Nacos 拉 `{服务名}-{profile}.yaml`（如 `gateway-prod.yaml`）覆盖本地
- 默认 `false`，用本地 profile，不依赖 Nacos 配置（服务注册发现不受影响）

### Nacos 侧需要建的 DataId（启用时）

本目录的 `*.yaml` 是**无 profile 后缀**的旧版，启用 Nacos 后按 profile 建：

| DataId | 对应 |
|---|---|
| `gateway-dev.yaml` / `gateway-prod.yaml` | gateway 路由 |
| `ticket-service-dev.yaml` / `ticket-service-prod.yaml` | 工单服务 |
| `user-service-dev.yaml` / `user-service-prod.yaml` | 用户服务 |
| `consultation-service-dev.yaml` / `consultation-service-prod.yaml` | 咨询服务（同一数据库） |
| `common-config.yaml` | JWT 共享密钥（无需改） |

> 内容直接从各服务的 `application-{profile}.yml` 复制即可（两者保持一致）。

## 配置加载优先级（高 → 低）

1. 命令行 `--spring.profiles.active=xxx`
2. 环境变量 `SPRING_PROFILES_ACTIVE`
3. **Nacos 配置**（`NACOS_CONFIG_ENABLED=true` 时，覆盖下面）
4. 本地 `application-{profile}.yml`
5. 本地 `application.yml`

## 维护纪律

- 改业务配置：**只改本地 `application-{profile}.yml`**，重新打包即可（dev 阶段）
- 启用 Nacos 后：业务配置在 Nacos 控制台改，本地 profile 作为基线/兜底，两边保持同步
- 敏感项（数据库密码/JWT密钥）：永远不写死进 prod 配置，走环境变量

单库合并后请以各模块当前 `application-{profile}.yml` 为准重新发布；所有服务设置相同的 `MYSQL_DB=it_ticket_system`，时区为 UTC。旧 Nacos 配置若仍指向其他库，会覆盖本地正确配置。AI 密钥不写入导入示例；保留环境变量或模块目录下的忽略文件。
