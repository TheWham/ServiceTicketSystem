# 尝试在 Azure、Office 365 或 Intune 中重置密码时出错：我们没有及时收到你的响应，或者你挂断了呼叫

本文介绍尝试在 Microsoft Azure、Office 365 或 Microsoft Intune 中重置密码时收到错误消息的问题。

*原始产品版本：*Microsoft Entra ID、Microsoft Intune、云服务（Web 角色/辅助角色）  
*原始 KB 数：* 2951259

## 现象

尝试在 Azure Microsoft、Microsoft 办公室 365 或 Microsoft Intune 中重置密码时，会收到以下错误消息：

> 我们没有及时收到你的回复，或者你挂断了电话。

## 原因

出现此问题的原因是以下任一项：

- 按下了错误的按钮，而不是英镑（#）按钮。
- 在点击英镑（#）按钮之前，你挂断了。
- 你没有回答。
- 我们在文件上拥有的电话号码可能不正确，我们无法联系你。

## 按下了错误的按钮而不是磅号 （#） 按钮

若要解决此问题，请在接听呼叫后按井号按钮。

## 在点击英镑（#）按钮之前，你挂断了

若要解决此问题，请在接听呼叫后按井号按钮。

## 你没有回答

也许你错过了电话。 若要解决此问题，必须接听呼叫。

## 我们在文件中使用的电话可能不正确，我们无法联系你

若要解决此问题，请与管理员协作更新电话号码。

注意

如果可用，请尝试使用其他方法，例如使用移动电话、办公电话或移动应用。
