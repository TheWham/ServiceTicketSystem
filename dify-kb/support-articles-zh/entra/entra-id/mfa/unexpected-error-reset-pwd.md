# 尝试在 Azure、Office 365 或 Intune 中重置密码时出错：Oops！ 我们在联系你时遇到意外错误

本文介绍尝试在 Microsoft Azure、Office 365 或 Microsoft Intune 中重置密码时收到错误消息的问题。 若要解决此问题，请与管理员协作更新电话号码。

*原始产品版本：*Microsoft Entra ID、Microsoft Intune、云服务（Web 角色/辅助角色）  
*原始 KB 数：* 2951260

## 现象

尝试在 Azure Microsoft、Microsoft 办公室 365 或 Microsoft Intune 中重置密码时，会收到以下错误消息：

> 糟糕！ 我们在联系你时遇到意外错误。

## 原因

之所以出现此问题，是因为我们在文件上拥有的电话号码可能不正确，我们无法联系到你。

## 解决方法

若要解决此问题，请与管理员协作更新电话号码。

注意

如果可用，请尝试使用其他方法，例如使用移动电话、办公电话或移动应用。
