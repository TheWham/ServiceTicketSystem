# 排查 Azure 多重身份验证问题

本文包含的信息可帮助排查在将 Windows 多重身份验证用于 Microsoft 办公室 365 或 Microsoft Azure 时可能会遇到的常见问题。

*原始产品版本：* 云服务（Web 角色/辅助角色）、Microsoft Entra ID、Microsoft Intune、Azure 备份、Office 365 标识管理  
*原始 KB 数：* 2937344

## 总结

| 场景 | 内容 |
| --- | --- |
| 你未收到包含 Azure 多重身份验证验证码的文本或语音呼叫 | [2834956](https://support.microsoft.com/help/2834956) |
| “对不起！ 尝试为 Azure 多重身份验证设置安全验证设置时，无法处理请求“错误 | [2909939](https://support.microsoft.com/help/2909939) |
| 丢失手机或手机号码更改后无法使用 Azure 多重身份验证登录到云服务 | [2834954](https://support.microsoft.com/help/2834954) |
| 尝试使用 Azure 多重身份验证登录时，“未收到预期响应”错误消息 | [2834968](https://support.microsoft.com/help/2834968) |
| 尝试使用工作或学校帐户登录时，“帐户验证系统遇到问题”错误消息 | [2834966](https://support.microsoft.com/help/2834966) |
| 无法使用工作或学校帐户登录到Office 应用 | [2834958](https://support.microsoft.com/help/2834958) |
| 无法登录到 Office 365、Azure 或 Intune | [2412085](https://support.microsoft.com/help/2412085) |
