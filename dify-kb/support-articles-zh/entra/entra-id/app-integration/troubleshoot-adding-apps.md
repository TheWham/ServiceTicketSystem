# 排查添加或删除应用程序以Microsoft Entra ID 的常见问题

## 概要

本系列文章提供了有关如何排查在 Microsoft Entra ID 中添加或删除应用程序时可能出现的问题的指导。

## 应用程序需要很长时间才能显示

请参阅应用程序需要很长时间才能显示[一文](app-takes-long-time-appear)，了解排查和解决此问题的步骤。

## 应用程序未显示

请参阅“应用程序”一[文](app-doesnt-appear)，了解排查和解决此问题的步骤。

## 无法删除应用程序

有关排查和解决此问题的步骤，请参阅文章 [：无法删除应用程序](unable-delete-app) 。

## 向Microsoft支持发送通知详细信息

请参阅文章 [“发送通知详细信息”以Microsoft支持](send-notification-details) 人员，了解如何查看门户通知的详细信息并将其发送给支持工程师。

## 详细信息

如果需要有关了解应用程序的帮助， [有关如何将 SaaS 应用与 Microsoft Entra ID](/zh-cn/azure/active-directory/saas-apps/tutorial-list) 一起集成的教程列表是一个很好的起点。

除此之外， [Microsoft Entra 应用程序文档库](/zh-cn/azure/active-directory/manage-apps/what-is-application-management) 可帮助你详细了解 Microsoft Entra ID 的单一登录及其工作原理。
