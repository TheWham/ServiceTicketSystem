# 单击“添加”按钮后，应用程序不会显示

## 概要

将应用程序添加到 Microsoft Entra ID 的过程有时可能由于暂时性问题、网络问题或已知问题而失败。 如果在单击“添加”按钮时遇到错误，则会看到一个处于“错误”状态的通知，指示创建应用程序时出错。 若要了解有关错误的详细信息或与支持工程师共享错误，可以按照如何查看门户通知[的详细信息中的步骤](send-notification-details)操作。
