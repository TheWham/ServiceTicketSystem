# 尝试安装 Azure Active Directory 同步工具时出错：计算机必须加入域

## 概要

本文提供有关解决在尝试安装 Azure Active Directory 同步工具时出现“计算机必须加入域”错误的指南。

*原始产品版本：* 云服务（Web 角色/辅助角色）、Microsoft Entra ID、Microsoft Intune、Azure 备份、Office 365 标识管理  
*原始 KB 数：* 2419250

## 现象

尝试安装 Microsoft Azure Active Directory 同步工具时，可能会收到以下错误消息：

> 必须将计算机加入到域中。

## 原因

如果计算机未加入Active Directory 域服务（AD DS）域，或者计算机未使用其域名系统（DNS）注册主机（A）资源记录，则可能会出现此问题。

## 解决方法

若要解决此问题，请使用以下任一方法。

### 方法 1：计算机未加入 AD DS 域

将计算机加入 AD DS 域。 为此，请按照下列步骤进行操作：

1. 在要加入域的计算机上，选择“开始”**，选择**控制面板**，然后双击“**系统**”。**
2. 在“计算机名称”、“域”和“工作组设置”下**，选择“**更改设置**”。**
3. 在 **“计算机名称** ”选项卡上，选择“ **更改**”。
4. 在“成员**”下**，选择“域**”**，键入此计算机将加入的域的名称，然后选择“**确定**”。
5. 选择“确定**”**，然后重新启动计算机。

### 方法 2：计算机已加入 AD DS 域

如果计算机已加入 AD DS 域，请确保计算机的 DNS 设置正确，并且计算机的主机 （A） 资源记录已注册到 DNS。 为此，请按照下列步骤进行操作：

1. 打开网络连接。
2. 右键单击要设置的网络连接，然后选择“ **属性**”。
3. 根据要设置的连接，执行下列操作之一：

   - 对于局域网连接：在 **“常规** ”选项卡上，选择 **“Internet 协议”（TCP/IP），**然后选择“ **属性**”。
   - 对于所有其他连接：在 **“网络** ”选项卡上，选择“ **Internet 协议”（TCP/IP），**然后选择“ **属性**”。
4. 如果要从动态主机配置协议 （DHCP） 服务器获取 DNS 服务器地址，请选择“ **自动**获取 DNS 服务器地址”。
5. 如果要手动配置 DNS 服务器地址，请选择“ **使用以下 DNS 服务器地址”。** 在 **“首选 DNS 服务器”框中，键入首选 DNS 服务器的** IP 地址。 在 **“备用 DNS 服务器”框中，键入备用 DNS 服务器的** IP 地址。
6. 选择“ **确定** ”两次，然后关闭网络连接。
7. 在命令提示符处，键入以下命令，并在每个命令后按 Enter：

   ```
   ipconfig /flushdns
   ```

   ```
   ipconfig /registerdns
   ```
8. 如果问题未解决，请重启已安装目录同步工具的计算机。
9. 如果问题仍未解决，请确保安装了目录同步工具的计算机可以与运行 AD DS 的计算机通信。
