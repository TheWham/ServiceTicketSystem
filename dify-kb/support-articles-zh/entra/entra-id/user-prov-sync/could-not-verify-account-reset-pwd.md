# 尝试在 Azure、Office 365 或 Intune 中重置密码时出错：无法验证帐户

本文介绍尝试在 Microsoft Azure、Office 365 或 Microsoft Intune 中重置密码时收到错误消息“我们无法验证帐户”的问题。 若要解决此问题，请与管理员协作更新电话号码。

*原始产品版本：*Microsoft Entra ID、Microsoft Intune、云服务（Web 角色/辅助角色）  
*原始 KB 数：* 2951246

## 现象

使用 Microsoft Azure、Microsoft 办公室 365 或 Microsoft Intune 时，尝试重置密码时可能会收到以下错误消息：

> 我们无法验证帐户。

## 原因

此问题可能发生，因为文件中没有电话号码可供你使用。

## 解决方法

若要解决此问题，请与管理员协作更新电话号码。
