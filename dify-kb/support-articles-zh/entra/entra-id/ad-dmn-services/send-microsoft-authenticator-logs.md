# 发送Microsoft验证器日志并获取事件 ID

按照以下步骤将日志发送到客户支持并获取事件 ID。

1. 打开 Microsoft Authenticator。
2. 点击 **应用顶部菜单中的“发送反馈** ”。
3. 选择 **“遇到问题？”**。
4. 填写表单，然后选择“ **发送** ”以发送反馈和日志。
5. 记下事件 ID。 如果你与Microsoft 支持部门联系，你或你的管理员将需要此 ID。
