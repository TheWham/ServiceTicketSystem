# 不能为 Windows 8.1 和 Windows 8 中的应用程序设置双面（双面）打印选项

本文提供了一个问题的解决方法，即无法为应用程序设置双面（双面）打印选项。

*适用于：*Windows 10 - 所有版本  
*原始 KB 数：* 3022505

## 现象

出现此问题时，打印的文档不遵循你在双面打印选项中部署的设置。

## 原因

出现此问题的原因是双面打印选项当前使用“设备”超级按钮设置。

## 解决方法

若要解决此问题，请按照以下步骤更改双面打印选项。

### Windows 8

1. 打开要打印的项目。
2. 从屏幕右边缘轻扫，点击“设备”，然后点击“打印”。 如果使用鼠标，请指向屏幕右下角，向上移动鼠标指针，单击“设备”，然后单击“打印”。
3. 从列表中选择打印机。 现在可以查看项目的预览。
4. 在此窗格中显示双工打印**时**，可以更改设置。 否则，点击或单击“ **更多设置**”。 显示双工打印**时**，可以更改设置。
5. 点击或单击“打印”以打印项目。

注意

如果步骤 4 中从未显示双工打印选项，打印机设备可能无法使用双面打印选项。 可以使用另一台打印机并从步骤 3 开始重试。

### Windows 8.1

1. 打开要打印的项目。
2. 从屏幕右边缘轻扫，点击 **“设备”**，然后点击“ **打印**”。 如果使用鼠标，请指向屏幕右下角，向上移动鼠标指针，单击“设备**”**，然后单击“**打印**”。
3. 从列表中选择打印机。 现在可以查看项目的预览。
4. 在此窗格中显示双工打印**时**，可以更改设置。 否则，点击或单击“ **更多设置**”。 显示双工打印**时**，可以更改设置。
5. 若要将双面打印设置为所选打印机的默认设置，请选择 **“在所有应用程序** ”选项中使用这些设置。
6. 点击或单击“打印**”**以打印项目。

注意

如果步骤 4 中从未显示双工打印选项，打印机设备可能无法使用双面打印选项。 可以使用另一台打印机并从步骤 3 开始重试。

## Status

Microsoft 已经确认这是一个列于“适用范围”部分的 Microsoft 产品问题。
