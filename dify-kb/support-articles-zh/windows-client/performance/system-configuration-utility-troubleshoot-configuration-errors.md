# 如何使用系统配置实用工具排查配置错误

本文介绍如何使用系统配置实用工具排查配置错误。

*适用于：* Windows Vista  
*原始 KB 数：* 950093

## 简介

本文介绍如何使用系统配置实用工具（Msconfig.exe）排查可能阻止 Windows Vista 正确启动的配置错误。

## 详细信息

系统配置实用工具查找并隔离问题。 但是，它不是启动管理计划。

有关如何禁用或永久删除 Windows 启动时运行的程序的详细信息，请单击以下文章编号以查看Microsoft知识库中的文章：

270035如何禁用启动 Windows XP 家庭版或 Windows Vista 时运行的程序

### 高级故障排除

这些故障排除步骤适用于高级计算机用户。 如果你对高级故障排除不满意，你可能想要请求某人寻求帮助或联系支持人员。 有关如何联系支持人员的信息，请访问以下Microsoft网站：  
[Microsoft 支持部门](https://support.microsoft.com/contactus/)  
系统配置实用工具自动执行Microsoft客户支持服务专业人员诊断系统配置问题时使用的例行故障排除步骤。

使用此实用工具时，可以选择用于在 Windows 启动过程中暂时阻止服务和程序加载的选项。 在此过程中，在使用注册表编辑器时，可以降低键入错误的风险。 此外，使用实用工具时，可以轻松还原原始配置。

使用系统配置实用工具时，可以在禁用常用服务和启动程序时启动 Windows。 然后，可以一次启用一个。 如果在禁用服务但启用服务时未发生问题，则服务可能是问题的原因。

可以轻松重置或更改 Windows Vista 中的配置设置，以包括以下设置的首选项：

- 启动选项
- 在启动过程中设置为启动的服务
- 在启动过程中设置为加载的程序

  注意

  这些程序在“程序/启动”文件夹和注册表中指定。

  注意

  若要使用系统配置实用工具，必须以管理员身份或管理员组成员身份登录。

### 可用的启动选项

以下启动选项可用：

- 正常启动
- 诊断启动
- 选择性启动

#### 正常启动

正常的启动选项是 Windows 默认值。 此选项使 Windows 能够与加载的所有程序、服务和设备驱动程序一起以正常模式启动。

#### 诊断启动

诊断启动选项使 Windows 能够确定启动 Windows 时要加载的基本设备驱动程序和软件。 使用此选项时，系统会暂时禁用Microsoft 服务，例如以下服务：

- 网络
- “即插即用”
- 事件日志记录
- 错误报告
- “系统还原”

注意

如果必须使用Microsoft服务来测试问题，请不要使用此选项。

若要执行诊断启动，请执行以下步骤：

1. 单击“开始”![](media/system-configuration-utility-troubleshoot-configuration-errors/vista-start-button.png)，键入`msconfig`“**开始搜索**”框，然后按 Enter。

   ![](media/system-configuration-utility-troubleshoot-configuration-errors/security-shield.png)
   如果系统提示输入管理员密码或确认，请键入密码，或单击“ **继续**”。
2. 在**“常规**”选项卡上，单击“诊断启动**”**，然后单击“**确定**”。
3. 单击“重启”。

如果在 Windows 重启后未出现问题，请使用选择性启动选项通过禁用和启用单个服务和启动程序来尝试查找问题。

#### 选择性启动

选择性启动选项使你能够选择希望计算机在重新启动计算机时加载的程序和服务。 您可以选择以下选项：

- **加载系统服务**
- **加载启动项**
- **使用原始启动配置**

默认情况下，会选择所有这些选项。 以下规则适用于以下选项：

- 单击以选中复选框时，重启计算机时将处理该选项。
- 单击清除复选框时，重启计算机时不会处理该选项。
- 选中该复选框且无法单击以清除复选框时（因为它不可用）时，当重启计算机时，某些项目仍在从该选项加载。
- 如果未选中该复选框，并且无法单击以选中该复选框，因为它不可用，则该选项不存在在计算机上。
- 无法更改 **“使用原始启动配置** ”选项。

注意

单击清除**“加载系统服务**”复选框时，将禁用Microsoft 服务，例如以下服务：

- 网络
- “即插即用”
- 事件日志记录
- 错误报告
- “系统还原”

如果必须使用Microsoft服务来测试问题，请不要单击以清除此复选框。

若要执行选择性启动并排查问题，请执行以下步骤：

1. 单击“开始”![](media/system-configuration-utility-troubleshoot-configuration-errors/vista-start-button.png)，键入`msconfig`“**开始搜索**”框，然后按 Enter。

   ![](media/system-configuration-utility-troubleshoot-configuration-errors/security-shield.png)
   如果系统提示输入管理员密码或确认，请键入密码，或单击“ **继续**”。
2. 在**“常规**”选项卡上，单击“选择性启动**”**，然后单击以清除**“加载系统服务和加载启动项**”复选框。
3. 单击“确定**”**，然后单击“**重启**”。

如果在计算机重启后可以重现问题，则此问题与系统服务或启动项无关。 在这种情况下，系统配置实用工具不会帮助排查该问题。

如果计算机重启后无法重现问题，则此问题与系统服务或启动项相关。 若要确定问题相关的项，请执行以下步骤：

1. 单击“开始”![](media/system-configuration-utility-troubleshoot-configuration-errors/vista-start-button.png)，键入`msconfig`“**开始搜索**”框，然后按 Enter。

   ![](media/system-configuration-utility-troubleshoot-configuration-errors/security-shield.png)
   如果系统提示输入管理员密码或确认，请键入密码，或单击“ **继续**”。
2. 在 **“常规** ”选项卡上，单击“ **选择性启动**”，然后单击以选中 **“加载系统服务** ”复选框。
3. 单击“确定**”**，然后单击“**重启**”。

如果可以在计算机重启后重现问题，则此问题与其中一个系统服务相关。 否则，该问题与其中一个启动项相关。

确定问题相关的项后，请按照“如何确定导致问题的服务或启动项”部分中的步骤确定导致问题的单个服务或启动项。

### 如何确定导致问题的服务或启动项

若要确定问题的原因，可以阻止重启计算机时加载单个服务和启动项。 可以按照以下步骤操作。

#### 如何确定导致问题的系统服务

1. **单击“服务**”选项卡，单击“**全部**禁用”，选中列出的第一个服务的复选框，然后重新启动计算机。

   如果问题未发生，可以消除第一个服务作为原因。
2. 选中第一个服务后，单击以选中第二个服务的复选框，然后重新启动计算机。
3. 重复此过程，直到重现问题。 如果无法重现此问题，可以消除系统服务作为原因。 继续执行下一过程。

#### 如何确定导致问题的启动项

1. **单击“常规**”选项卡，然后单击以选中“**加载启动项**”复选框。
2. **单击“启动**”选项卡，单击“**全部**禁用”，选中列出的第一个启动项的复选框，然后重启计算机。

   如果问题未发生，可以消除第一个启动项作为原因。
3. 选中第一个启动项后，单击以选中第二个启动项的复选框，然后重新启动计算机。
4. 重复此过程，直到重现问题。

### 如何启用和禁用单个服务和启动项

#### 服务和启动选项

系统**配置实用工具中的“服务和****启动**”选项卡具有以下选项：

- 复选框使你能够启用或禁用选项。 若要启用或禁用某个选项以便在启动时加载或不加载，请单击以选中或单击以清除复选框。 选中的复选框指示将在启动时启动或加载该选项。
- 使用键盘箭头键可以在没有鼠标时浏览不同的选项。
- 使用空格键，可以在没有鼠标时选择和清除选项。

注意

单击此项清除复选框时，**将自动选择“常规**”选项卡上的**“选择性启动**”选项。

#### 如何返回到正常启动

完成故障排除并修复配置后，返回到正常启动。 可以按照以下步骤操作：

1. 单击“开始”![](media/system-configuration-utility-troubleshoot-configuration-errors/vista-start-button.png)，键入`msconfig`“**开始搜索**”框，然后按 Enter。

   ![](media/system-configuration-utility-troubleshoot-configuration-errors/security-shield.png)
   如果系统提示输入管理员密码或确认，请键入密码，或单击“ **继续**”。
2. 在**“常规**”选项卡上，单击“正常启动**”**，然后单击“**确定**”。
3. 单击“重启”。

### 如何启动诊断工具和其他高级工具

可以使用 **系统配置实用工具中的“工具** ”选项卡启动诊断工具和其他高级工具。 “ **工具** ”选项卡还显示工具的路径和开关。

若要启动“工具”**选项卡上列出的**一个或多个工具，请单击要启动的工具，然后单击“**启动**”。 或者，单击要启动的工具，然后按 Alt+L。
