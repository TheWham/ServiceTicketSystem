# Windows 客户端性能故障排除文档

本节中的主题提供解决方案和方案指南，可帮助你排查和自行解决与性能相关的问题。 这些主题分为子类别。 浏览内容或使用搜索功能查找相关内容。

## 性能子类别

- 应用程序
- 蓝屏/错误检查
- 无启动（不是 BugChecks）
- 性能监视工具
- 服务
- 关机速度缓慢或卡住
- 性能较低
