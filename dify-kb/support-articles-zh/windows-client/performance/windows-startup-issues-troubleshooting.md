## 工作原理

当Microsoft Windows 遇到破坏安全系统操作的条件时，系统将停止。 这些 Windows 启动问题分为以下组：

- Bug 检查：也称为系统崩溃、内核错误或停止错误。
- 无启动：系统可能不会生成 bug 检查，但无法启动到 Windows。
- 冻结：也称为“系统挂起”。
