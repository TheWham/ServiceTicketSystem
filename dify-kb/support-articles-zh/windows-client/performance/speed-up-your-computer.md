# 加快 Windows 8.1 计算机的速度

无论你对保持计算机保持干净和最新状态有多好，它们往往在一段时间后变慢。 幸运的是，有很多方法可以帮助加快速度，而无需升级硬件。

*适用于：* Windows 8.1  
*原始 KB 数：* 3064207

注意

如果你是高级用户，可以从Microsoft网站下载 [免费工具](/zh-cn/sysinternals/downloads/autoruns) ，其中显示了启动 Windows 时运行的所有程序和进程，包括 Windows 需要成功操作的程序和进程。 只有在发生错误后，你才愿意还原 Windows，才使用此工具。

## 卸载额外的防病毒程序

如果同时使用多个防病毒或反间谍程序，则设备可能会遇到性能下降、变得不稳定或意外重启。 若要解决此问题，应选择要在设备上运行的一个 Internet 安全程序。 然后，应卸载其他程序。

注意

在卸载其他安全程序之前，请确保已在设备上运行 Internet 安全程序。

有些 Internet 安全应用程序无法完全卸载。 可能需要为以前的安全应用程序下载并运行清理实用工具才能完全删除它。

如果将另一个反间谍程序与 Microsoft Security Essentials 一起使用，建议关闭其他程序中的实时扫描。 有关详细信息，请参阅该反间谍程序提供的文档。

若要删除防病毒或反间谍程序，请按照以下说明操作：

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或选择“ **搜索**”。
3. *在**“搜索**”框中键入appwiz.cpl*。
4. 点击或选择**搜索**框下方**的Appwiz.cpl**。
5. 在已安装的程序列表中，卸载不需要的 Internet 安全程序。
6. 重启设备。

## 关闭通过启动运行的通知区域中的程序

如果设备需要很长时间才能启动，则其中一个原因可能是具有大量启动应用或一些对启动时间产生重大影响的应用。

其中一些程序将图标添加到任务栏上的通知区域，以显示它们正在启动时运行。

若要停止具有下列图标之一的程序在启动时自动运行，请按照以下说明操作：

1. 指向图标托盘中的每个图标以查看程序名称。
2. 若要确保可以看到所有正在运行的程序的图标，请从屏幕右边缘轻扫（如果使用鼠标，请指向屏幕右上角并向下移动鼠标指针），然后点击或选择“ **搜索**”。
3. 键入*“搜索”**框中显示隐藏的图标***。
4. 点击或选择任务栏**上的“**显示”或隐藏非活动图标。
5. 选中 **“始终在任务栏**上显示所有图标和通知”。

注意

必须打开任何不希望在启动时运行的程序并更改设置。

## 查看启动项

若要查看在启动时运行哪些程序并禁用任何程序，请按照以下说明操作：

1. 按住或右键单击任务栏上的空白区域，然后选择 **任务管理器**。
2. 点击或选择**任务管理器**左下角的**更多详细信息**。
3. 在**任务管理器**的**“启动**”选项卡下，可以查看每次打开设备并登录到 Windows 时自动启动的应用程序列表。
4. 如果在此列表中看到不希望在 Windows 启动时运行的任何程序，请点击或选择应用程序，然后点击或选择“ **禁用**”。

注意

禁用程序在启动时运行不会阻止程序在需要时运行。 如果在启动后点击或选择程序，它将正常启动并运行。

## 更改程序

有时，通过添加或删除某些程序选项，可以阻止程序在启动时运行。

如果无法阻止程序在启动时运行，并且程序没有更改配置的选项，则必须与程序制造商联系以获取解决方案。

若要更改程序的配置，请按照以下说明操作：

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或选择“ **搜索**”。
3. *在**“搜索**”框中键入appwiz.cpl*。
4. 点击或选择**搜索**框下方**的Appwiz.cpl**。
5. 点击或选择某个程序，然后点击或选择“卸载”、“更改”或**“**修复**”。**

如果出现提示，请键入管理员密码或确认。

## 清理磁盘错误

随着时间的推移，你的设备可能会在其硬盘驱动器上创建错误。 这些错误可能会降低设备速度。 检查磁盘程序可识别并清除任何错误。

若要运行检查磁盘，请按照以下说明操作：

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或选择“ **搜索**”。
3. *在**“搜索**”框中键入计算机*。
4. 点击或选中“搜索**”框下方的**“**此电脑**”。
5. 按住或右键单击要修复的驱动器，然后点击或选择“ **属性**”。
6. 点击或选择“ **工具** ”选项卡。
7. 在“错误检查**”下**，点击或选择“**检查**”。 根据硬盘的大小，这可能需要几分钟时间。 为获得最佳结果，在检查错误时不要将设备用于任何其他任务。 如果出现提示，请键入管理员密码或确认。
8. 完成错误检查后，可能需要重启设备。

## 对硬盘进行碎片整理

帮助提高设备性能的最佳方法之一是优化硬盘驱动器。 优化驱动器（以前称为磁盘碎片整理程序）是一项 Windows 功能，可帮助优化不同类型的驱动器。 该功能按每周计划自动运行，但也可以手动运行优化驱动器。

若要手动运行优化驱动器，请按照以下说明操作：

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或选择“ **搜索**”。
3. *在**“搜索**”框中键入计算机*。
4. 点击或选中“搜索**”框下方的**“**此电脑**”。
5. 按住或右键单击要修复的驱动器，然后点击或选择“ **属性**”。
6. 点击或选择“ **工具** ”选项卡。
7. 点击或选择“优化”和“碎片整理”驱动器**下的**“优化”。
8. 在“状态”**下**，点击或选择要优化的驱动器。 （The **媒体类型** 列会告诉你要优化的驱动器类型。
9. 若要确定驱动器是否需要优化，请点击或选择“ **分析**”。

   注意

   如果出现提示，请键入管理员密码或确认。
10. Windows 完成对驱动器的分析后，请检查 **“当前状态** ”列以查看是否需要优化驱动器。 如果驱动器碎片超过 10%，则应对其进行优化。
11. 点击或选择“ **优化**”。

注意

- 优化驱动器可能需要几分钟到几个小时才能完成，具体取决于驱动器的大小和所需的优化程度。 在优化过程中，你仍然可以使用设备。
- 如果驱动器由另一个程序使用，或者使用 NTFS、FAT 或 FAT32 以外的文件系统进行格式化，则无法对其进行优化。
- 无法优化网络驱动器。
- 如果驱动器未显示在“优化驱动器”中，可能是因为它包含错误。 请先尝试修复驱动器，然后返回到“优化驱动器”以重试。

若要更改优化计划，请按照以下说明操作：

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或选择“ **搜索**”。
3. *在**“搜索**”框中键入计算机*。
4. 点击或选中“搜索**”框下方的**“**此电脑**”。
5. 按住或右键单击要修复的驱动器，然后点击或选择“ **属性**”。
6. 点击或选择“ **工具** ”选项卡。
7. 点击或选择“优化”和“碎片整理”驱动器**下的**“优化”。
8. 点击或选择“ **更改设置**”。 如果出现提示，请键入管理员密码或确认。
9. 请选择以下选项之一：

   - 若要关闭计划优化，请清除 **“按计划** 运行”复选框。
   - 若要更改计划优化的频率，请点击或选择频率旁边的**下拉列表，然后点击或选择“每日**”、“**每周**”或**“**每月”。**** 优化的默认计划是每周一次，在自动维护期间运行。
   - 若要选择要在计划优化中包含或排除的驱动器，请点击或选择驱动器旁边的“ **选择** ”。 选中或清除驱动器旁边的复选框，然后点击或选择“确定”。 如果不希望将新驱动器添加到计划优化，还可以清除 **“自动优化新驱动器** ”复选框。 如果 Windows 无法优化驱动器，它不会提供驱动器作为自动维护的选项。
10. 点击或选择“ **确定**”。

## 清理硬盘

磁盘清理通过删除临时文件和系统文件、清空回收站以及删除可能不再需要的其他各种项目来减少驱动器上不必要的文件数。

若要清理硬盘，请按照以下说明操作：

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或选择“ **搜索**”。
3. *在**“搜索**”框中键入磁盘空间*。
4. 点击或选择**“释放磁盘空间”，方法是在“搜索**”框下方**删除不必要的文件**。
5. 在 **“驱动器** ”列表中，点击或选择要清理的驱动器。
6. 点击或选择“ **确定**”。
7. 在出现的邮件中，点击或选择“ **删除文件**”。

若要清理与帐户关联的系统文件，请按照以下说明操作：

1. 在 **“驱动器** ”列表中，点击或选择要清理的驱动器，然后点击或选择“ **确定**”。
2. 在“磁盘清理”对话框中，点击或选择“ **清理系统文件**”。

   注意

   如果出现提示，请键入管理员密码或确认。
3. 选择从设备清理系统文件时，可以使用“ **更多选项** ”选项卡。 此选项卡包括两个用于释放空间的其他选项：
   - **程序和功能**。 此选项将在控制面板**中**打开**程序和功能**，你可以在其中卸载不再使用的程序。 “程序和功能”**中的**“大小**”列显示每个**程序使用的空间。
   - **系统还原和卷影副本**。 系统还原使用还原点将系统文件返回到较早的时间点。 如果设备正常运行，可以通过删除以前的还原点来节省空间。

## 关闭视觉效果

如果 Windows 运行缓慢，可以通过禁用某些视觉效果来加快速度。 你可以逐个选择要关闭的视觉效果，也可以让 Windows 为你选择。

若要关闭视觉效果，请按照以下说明操作：

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或选择“ **搜索**”。
3. *在**“搜索**”框中键入性能信息和工具*。
4. 点击或选择“**在搜索**”框下方**调整 Windows** 的外观和性能。
5. 在“视觉效果**”选项卡下**，选中“**调整”以获取最佳性能**，然后点击或选择“**确定**”。 （对于不太激烈的选项，请选择 **让 Windows 选择最适合我的计算机**的内容。

## 同时运行更少的程序

有时可以通过更改计算行为来提高系统性能。 在打开多个浏览器窗口时运行四个或多个程序，电子邮件可能比设备可以处理更多。

如果发现设备速度变慢，请决定是否确实需要同时保持所有程序和窗口的打开状态。 此外，请找到一种方法来提醒自己以后回复电子邮件，而不是让他们保持打开状态，直到答复。

## 使用 ReadyBoost

ReadyBoost 可以使用闪存卡和 USB 闪存驱动器上的存储空间来加速设备。 如果你的存储设备将适用于 ReadyBoost，则当你将其插入设备时，你将看到使用 ReadyBoost 的选项。 如果选择此选项，可以选择要使用的内存量。

## 调整索引选项

Windows 使用索引对设备上的最常见文件执行非常快速的搜索。 如果搜索设备上的内容需要太长的时间，则可以缩小搜索范围以专注于最常使用的文件和文件夹。

## 调整电源计划

电源计划是一系列硬件和系统设置（例如显示、睡眠等），用于管理设备使用电源的方式。 可以使用的电源计划取决于你拥有的设备类型。
