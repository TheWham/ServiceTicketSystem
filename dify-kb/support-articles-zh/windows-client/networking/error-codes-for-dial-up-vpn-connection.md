# 拨号连接或 VPN 连接的错误代码列表

本文列出了在建立拨号连接或 VPN 连接时可能会收到的错误代码。

*原始 KB 数：* 824864

注意

仅当尝试连接到运行 Windows 2000 或更高版本的路由和远程访问服务器时，才会看到数字大于 900 的错误代码。
