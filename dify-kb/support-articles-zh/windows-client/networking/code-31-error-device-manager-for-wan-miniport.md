# Windows 中 WAN 微型端口（网络监视器）设备的设备管理器代码 31 错误

本文提供了一种解决方法，其中设备管理器在 WAN 微型端口（网络监视器）设备旁边显示黄色感叹号。

*原始 KB 数：* 2871372

## 现象

假设出现了下面这种情景：

- 正在安装 Windows。
- 安装完成后打开设备管理器。

在此方案中，设备管理器在 WAN 微型端口（网络监视器）设备旁边显示黄色感叹号。 此外， **设备属性窗口的“详细信息** ”选项卡会显示以下消息：

设备无法正常工作，因为 Windows 无法加载此设备所需的驱动程序。 （代码 31）

## 原因

出现此问题的原因是 Windows 无法加载 WAN（网络监视器）设备所需的驱动程序。 由于没有与设备关联的驱动程序，因此无法将其从设备管理器中删除。

## 解决方法

若要防止将来安装期间出现此问题，必须将更新 [2822241](https://support.microsoft.com/help/2822241) 集成到安装期间使用的安装介质中。

有关如何使用部署映像服务和管理（DISM）将修补程序包集成到安装介质的信息，请参阅 [脱机](https://technet.microsoft.com/library/hh824838.aspx)添加或删除包。

## 解决方法

如果已安装操作系统，并且当前在 WAN 微型端口（网络监视器）设备上收到“代码 31”错误，请执行以下步骤：

1. 打开“设备管理器”。
2. 右键单击 WAN 微型端口（网络监视器）设备，然后单击“ **更新驱动程序软件**”。
3. 单击“ **浏览我的计算机查找驱动程序软件**”。
4. 单击“ **让我从计算机上的**设备驱动程序列表中进行选择。
5. 清除“ **显示兼容的硬件** ”复选框。
6. 在左侧的列中，选择 **Microsoft**，在右侧的列中，选择 **Microsoft KM-TEST 环回适配器**。
7. 在**“更新驱动程序警告**”对话框中，单击“是**”**继续安装此驱动程序。
8. 安装驱动程序后，右键单击设备，然后单击“ **卸载**”。
9. 卸载设备后，右键单击设备管理器中的计算机名称，然后单击“**扫描硬件更改**”。
10. 在 **“视图** ”菜单上，单击“ **显示隐藏的设备**”。 WAN 微型端口（网络监视器）设备现在应启动，不再有黄色感叹号。
