# 如何连接到无线网络

本文介绍如何连接到无线网络。

*适用于：* Windows Vista  
*原始 KB 数：* 928429

注意

对未安装任何 Service Pack 的 Windows Vista 的支持已于 2010 年 4 月 13 日结束。 若要继续接收适用于 Windows 的安全更新，请确保运行具有 Service Pack 2（SP2）的 Windows Vista。 有关详细信息，请参阅此Microsoft网页： [某些版本的 Windows 支持即将结束](https://windows.microsoft.com/windows/help/end-support-windows-xp-sp2-windows-vista-without-service-packs)

## 简介

本文介绍如何连接到 Windows Vista 中的无线网络。

## 详细信息

与 Windows XP 一起使用以连接到无线网络的软件与 Windows Vista 不兼容。 或者，可以使用 Windows Vista 配置无线网络。

若要连接到 Windows Vista 中的无线网络，请执行以下步骤：

1. 单击“开始![](media/connect-to-wireless-network/vista-start-button.png)**”**，然后单击“**连接到”。**
2. 单击要连接到的无线网络，然后单击“ **连接**”。

   注意

   在连接过程中，系统可能会提示你输入有线等效隐私（WEP）密钥。 如果没有此密钥，请联系无线网络的管理员获取帮助。

有关如何使用 Windows Vista 连接到无线网络的详细信息，请访问以下Microsoft网站： <https://technet.microsoft.com/library/bb878035.aspx>  
对于无线广域网（2.5G/3G），通信软件由无线运营商提供。 请联系公司的 IT 经理，或拨打为 Windows Vista 兼容的软件提供服务的无线运营商。
