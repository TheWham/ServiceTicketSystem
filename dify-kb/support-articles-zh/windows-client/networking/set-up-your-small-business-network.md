# 建立小型企业网络

本文将指导你完成评估、准备和建立小型企业网络的步骤。 本文适用于帮助建立小型企业网络的 IT 专业人员。

## 评估网络类型

许多小型企业使用网络在计算机之间共享对 Internet、打印机和文件的访问权限。 拥有网络几乎肯定会使企业受益的同时，您需要根据企业独特而具体的需求，确定哪种网络类型最合适。 可供选择的类型包括有线、无线以及混合网络。
在为企业挑选网络时，你应当考虑两个主要问题 - 设备的位置以及希望可以达到的网速。 尽管不同网络类型之间的成本类似，但根据你选定的网络速度，价格会有所不同。

以下部分介绍了可供使用的不同网络选项。

### 有线网络

有线或以太网网络能够以 10 Mbps 到 1000 Mbps 的速度传输数据，具体取决于你使用的电缆类型。 千兆以太网速度最快，传输速度高达每秒 1 千兆（或 1000 Mbps）。

#### 优点

- 以太网安全性高且速度快。
- 以太网因为是全封闭式的而要比无线网络安全。
- 以太网不会受到物体或墙壁的干扰。

#### 缺点

- 必须在每台设备和集线器、交换机或路由器之间连接以太网电缆。 当设备位于不同的房间时，这一过程可能比较耗时且非常困难。
- 硬件成本比较高。

#### 硬件要求

| 硬件 | 数量 |
| --- | --- |
| 以太网络适配器 适配器将设备连接到网络，以便它们能够进行通信。 可以使用以太网电缆或 USB 电缆将网络适配器连接到 USB 端口，具体取决于适配器类型。 还可以将网络适配器安装在设备内。 | 网络上每台设备都需要一台适配器。 台式计算机通常具有内置适配器。 |
| 以太网集线器或交换机 集线器将数据从一台设备传递至另一台设备。 因为集线器无法识别数据源是来自于 Internet 还是另一台设备，所以其会将信息发送至所有连接的设备，包括发送信息的设备。 交换机工作原理类似于集线器。 但是，交换机还可识别信息的预期目标，因此只有预期设备会收到信息。 交换机成本稍贵于集线器，但其速度更快。 | 一个。 最好是 10/100/1000 集线器或交换机，并应具有足够的端口容纳网络上的所有设备。 |
| 以太网路由器（仅在你想要连接超过两台设备且共享 Internet 连接时需要） 路由器有助于在多台设备之间共享单个 Internet 连接。 不需要路由器即可建立有线网络，但如果希望多台设备共享 Internet 连接，则应使用路由器。 | 一个。 如果路由器没有足够的端口供所有设备使用，则可能需要使用额外的集线器或交换机。 |
| 调制解调器 设备使用调制解调器通过电话线或电缆线发送和接收信息。 如果想要连接到 Internet，你需要使用调制解调器。 | 一个。 |
| 以太网电缆 网络电缆将设备相互连接并连接到其他相关硬件，例如集线器、路由器和外部网络适配器。 | 适用于每个需要连接到网络集线器或交换机的设备。 最好是 10/100/1000 Cat 6 电缆，但不是必需的。 |

### 无线网络

无线网络可以 10-600 兆字节/秒 (Mbps) 的速度在任何地方传输数据，具体取决于调制解调器使用的无线标准类型。

#### 优点

- 由于没有电缆，可以轻松移动设备。
- 无线网络的安装成本要比有线网络更低。
- 通常，可以使用无线中继器改善无线信号。 无线中继器可以收集信号，如果信号减弱，中继器可以再次将其重播至满额强度。

#### 缺点

- 无线技术的传输速度通常比有线技术慢。
- 无线技术可能会受到墙壁、大型金属物体和管道的干扰。 此外，许多无绳电话和微波炉在使用时可能也会干扰无线网络。
- 无线网络的速度通常只有其额定速度的一半左右。

#### 硬件要求

| 硬件 | 数量 |
| --- | --- |
| 无线网络适配器 适配器将设备连接到网络，以便它们能够进行通信。 | 网络上每台设备都需要一台适配器。 便携设备通常具有内置适配器。 |
| 无线路由器 路由器有助于在多台设备之间共享单个 Internet 连接。 不需要路由器即可建立有线网络，但如果希望多台设备共享 Internet 连接，则应使用路由器。 | 一个。 |

如果设备具有内置无线功能，则无需无线网络适配器。

### 混合网络

混合网络使用无线和有线网络的组合，并提供这两种网络类型的最佳性能，以便可以使用更快的有线桌面和便携式无线移动设备，如笔记本电脑，平板电脑和智能手机。 混合网络依赖于特殊的混合路由器、集线器、交换机和以太网电缆来连接有线和无线设备。 混合路由器的任务有两个 - 广播无线信号和提供有线访问端口。 它最常被称为带以太网端口或“LAN 端口”的无线或 Wi-Fi 路由器。

混合有线/无线网络似乎在速度、移动性、可负担性和安全性方面相得益彰。 如果用户需要最大的 Internet 和文件共享速度，其可通过以太网电缆接入此网络。 如果他们需要在办公室走廊上共享流视频，则可以无线方式访问网络。 通过适当的规划，组织可以通过最大程度地扩大无线网络的覆盖范围，在 CAT5/CAT6 电缆和路由器上节省资金。 有了正确的加密和密码管理，网络的无线部分可以像有线一样安全。

| 硬件 | 数量 |
| --- | --- |
| 网络适配器 适配器将设备连接到网络，以便它们能够进行通信。 | 网络上每台设备都需要一台适配器。 桌面和便携式设备通常都内置了这些适配器。 |
| 混合路由器 路由器有助于在多台设备之间共享单个 Internet 连接。 不需要路由器即可建立有线网络，但如果希望多台设备共享 Internet 连接，则应使用路由器。 | 至少一个。 如果需要连接四个以上的有线设备，请额外增加一台有线路由器。 |
| 以太网电缆 网络电缆将设备相互连接并连接到其他相关硬件，例如集线器、路由器和外部网络适配器。 | 连接到网络集线器或交换机的每台设备都需要一条。 最好是 10/100/1000 Cat 6 电缆，但不是必需的。 |

## 安装有线网络

有线网络比无线网络更快、更安全、更可靠。 其还降低了外界干扰的几率。 同时，有线网络的建立要更费事，硬件方面的支出也更多。

注意

如果你的小型企业拥有较大的占地面积（如制造工厂），当设备之间电缆较长时，可能会出现信号衰减问题。 通常可以通过使用以太网中继器加强信号，从而改善信号质量。 首先，按照要连接至网络的设备上运行的 Windows 版本所适用的过程执行操作。 所有设备无需因为要连接至企业网络而运行同一版本的 Windows。

### 连接电缆

若要开始，请将以太网电缆从路由器或集线器连接至要连接至网络的各个设备。

#### 安装网络适配器

Windows 可为你自动检测并安装正确的网络适配器软件。

若要确定你的设备是否具备网络适配器，请按照以下说明进行操作。

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或单击“搜索”。
3. 在搜索框中，键入“设备管理器”。
4. 点击或单击“设置”。
5. 点击或单击屏幕左侧的“设备管理器”。
6. 要查看已安装的网络适配器列表，请展开“网络适配器”。

#### 设置路由器

如果路由器显示 Windows 徽标或短语“与 Windows 兼容”，则可以使用最新版本的 Windows 立即连接 (WCN) 进行自动设置。 除此以外，大多数路由器都会随附说明和设置 CD，可帮助你进行设置。

如果有合并调制解调器和路由器，请按照以下说明进行操作：

1. 将调制解调器插入电源插座。
2. 将电话线或电缆一端插入设备的广域网 (WAN) 端口，然后将另一端插入墙壁插孔。 WAN 端口应标记为“WAN”。（DSL 用户不应在电话线上使用 DSL 筛选器。
3. 将以太网电缆的一端插入设备的局域网 (LAN) 端口，然后将另一端插入要连接到 Internet 的设备的网络端口。 LAN 端口应该有“LAN”的标记。
4. 启动或重启设备。

#### 将路由器连接至 Internet

若要将路由器连接至 Internet，请按照以下说明进行操作。

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或单击“搜索”。
3. 点击或单击“搜索”框上方的“所有位置”旁边的向下箭头，然后点击或单击“设置”。
4. 在“搜索”框中，键入“网络和共享中心”。
5. 点击或单击搜索结果中的“网络和共享中心”。
6. 点击或单击“设置新的连接或网络”。
7. 点击或单击“连接到 Internet”。
8. 点击或单击“下一步”。

如果家庭或办公室以有线方式连接以太网，请设置房间中有以太网插孔的设备，然后将它们直接插入以太网插孔。

### 设置独立的调制解调器以连接到路由器

如果购买了单独的调制解调器和路由器，请按照以下说明进行操作：

1. 将调制解调器插入电源插座。
2. 将电话线或电缆的一端插入调制解调器，将另一端插入墙壁插孔。 （DSL 用户不应在电话线上使用 DSL 筛选器。）
3. 将以太网电缆的一端插入调制解调器，将另一端插入路由器上的广域网 (WAN) 端口。
4. 将路由器插入电源插座。
5. 将以太网电缆的一端插入路由器的局域网 (LAN) 端口，然后将另一端插入要连接到 Internet 的设备的网络端口。
6. 启动或重启设备。

### 将调制解调器连接到 Internet

按照说明将调制解调器连接到 Internet。

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或单击“搜索”。

### 设置防火墙

防火墙是有助于控制恶意软件在网络上传播并在使用 Internet 时保护设备的硬件或软件。

请勿关闭 Windows 防火墙，除非已打开另一个防火墙。 关闭 Windows 防火墙可能会使设备和网络容易受到黑客的破坏。
要设置防火墙，请按照说明操作：

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或单击“搜索”。
3. 在“搜索”框中键入“防火墙”。
4. 点击或单击“设置”。
5. 点击或单击屏幕左侧的“Windows 防火墙”。
6. 在左窗格中，点击或单击“开启或关闭 Windows 防火墙”。
7. 在要帮助保护的每种网络类型下，点击或单击“打开 Windows 防火墙”，然后点击或单击“确定”。

   注意

   系统可能会要求你输入管理员密码或确认你的选择。

#### 启用带防火墙的文件和打印机共享

共享内容或开启网络发现时，Windows 防火墙会自动打开文件和打印机共享的正确端口。 如果使用的是另一个防火墙，则必须自行打开这些端口，以便设备可以查找其他包含要共享的文件或打印机的设备。

要查找其他运行 Windows 8、Windows 7 或 Windows Vista 的设备，请打开以下端口：

- UDP 3702
- UDP 5355
- TCP 5357
- TCP 5358

要查找其他运行 Windows 早期版本的设备，以及在任何 Windows 版本上使用文件和打印机共享，请打开以下端口：

- UDP 137
- UDP 138
- TCP 139
- TCP 445
- UDP 5355

要查找网络设备，请打开以下端口：

- UDP 1900
- TCP 2869
- UDP 3702
- UDP 5355
- TCP 5357
- TCP 5358

如果运行 Windows 7 的设备通过电缆连接到集线器或交换机，则它们已经联网，并随时可用。

如果必须更改工作组名称，系统会提示重启设备。 重启设备，然后继续执行以下步骤。

1. 单击“启动”。
2. 单击“网上邻居”。
3. 在左窗格中的“网络任务”下，单击“查看工作组计算机”。
4. 从显示的列表中选择设备，然后单击“连接”。

## 安装无线网络

既然你决定为企业投资无线网络，则必须选择网络标准并设置网络。 无线网络 (WLAN) 在基础结构方面没有太多要求。 许多小型企业所有者都选择使用无线网络，原因在于无线网络比较灵活、便宜而且易于安装和维护。 你可以使用无线网络在办公室中共享 Internet 访问、文件、打印机、文件服务器和其他设备。 设置网络后，可以启用共享、设置权限以及添加打印机和其他设备。

首先，按照要连接至网络的设备上运行的 Windows 版本所适用的过程执行操作。 所有设备无需因为要连接至企业网络而运行同一版本的 Windows。

### 选择无线网络标准

最常见的无线网络标准为 802.11b、802.11g、802.11a 和 802.11n。 每种标准因为数据传输速度的不同而导致价格会有所不同。 一般情况下，数据传输速度越快，需要支付的费用就越高。 总的来说，每种标准的数据传输速度如下所示：

1. 802.11b - 每秒 11 兆字节 (Mbps)
2. 802.11g - 54 Mbps
3. 802.11a - 54 Mbps
4. 802.11n - 300-600 Mbps

注意

列出的传输时间均为理想条件下的时间。 由于硬件、Web 服务器、网络流量和其他因素的差异，这些时间不一定能够在典型情况下实现。

### 设置无线路由器

无线路由器使用无线电信号而非电线在网络和 Internet 之间发送信息。 应使用支持较快无线信号（如 802.11g 或 802.11n）的路由器。

要获得最佳结果，请将无线路由器、无线调制解调器路由器（带有内置无线路由器的 DSL 或电缆调制解调器），或无线接入点 (WAP) 置于办公室的中央位置。 如果路由器位于一楼而设备位于二楼，请将路由器放置在一楼某个架子的高处。

注意

金属物体、墙壁和地板都可能干扰路由器的无线信号。

### 选择无线网络标准

最常见的无线网络标准为 802.11b、802.11g、802.11a 和 802.11n。 每种标准因为数据传输速度的不同而导致价格会有所不同。 一般情况下，数据传输速度越快，需要支付的费用就越高。 总的来说，每种标准的数据传输速度如下所示：

1. 802.11b - 每秒 11 兆字节 (Mbps)
2. 802.11g - 54 Mbps
3. 802.11a - 54 Mbps
4. 802.11n • 300-600 Mbps

   注意

   列出的传输时间均为理想条件下的时间。 由于硬件、Web 服务器、网络流量和其他因素的差异，这些时间不一定能够在典型情况下实现。

要获得最佳结果，请将无线路由器、无线调制解调器路由器（带有内置无线路由器的 DSL 或电缆调制解调器），或无线接入点 (WAP) 置于办公室的中央位置。 如果路由器位于一楼而设备位于二楼，请将路由器放置在一楼某个架子的高处。

金属物体、墙壁和地板都可能干扰路由器的无线信号。

## 安装混合网络

混合网络是指包含两个或多个通信标准的任何计算机网络，例如以太网 (802.3) 和 Wi-Fi (802.11 a/b/g)。 混合网络依赖于特殊的混合路由器、集线器和交换机来连接有线和无线计算机以及其他启用网络的设备。 它使网络能够最大限度地发挥这两种网络类型的优势。

### 中心接入点

在有线计算机网络中，所有设备都通过物理电缆连接到中心接入点。 此接入点可以是路由器、集线器或交换机。 此接入点的功能是在多台设备之间共享网络连接。 所有设备都使用单独的以太网 (CAT 5) 电缆插入接入点。 如果设备也需要共享 Internet 连接，则将接入点插入宽带 Internet 调制解调器（电缆或 DSL）。

在标准无线网络中，所有联网设备都与广播信号的中心无线接入点通信。 设备本身需要包含符合一个或多个 Wi-Fi 标准（802.11 a、b 或 g）的无线调制解调器或卡片才能接收信号。 在此网络配置中，所有无线设备都可以通过网络相互共享文件。 如果他们还想共享 Internet 连接，则将无线接入点插入宽带 Internet 调制解调器。

标准混合网络使用混合接入点，即广播无线信号并包含有线接入端口的网络设备。 最常见的混合接入点是混合路由器。 典型的混合路由器使用 802.11 a、b 或 g 广播 Wi-Fi 信号，并包含四个用于连接有线设备的以太网端口。 混合路由器还有一个端口，用于通过以太网电缆连接到电缆或 DSL 调制解调器。

购买混合路由器时，可能不会在任何位置看到“混合”一词。 你更有可能看到路由器被宣传为带以太网端口或“LAN 端口”的无线或 Wi-Fi 路由器。

确定要使用电线连接和无线连接的设备后，请按照**安装有线网络**中列出的过程操作，并分别**安装无线网络**来设置混合网络的这些部分。

### 网络配置

混合网络有多种不同的网络配置。 最基本的配置是将所有有线设备插入混合路由器的以太网端口，以及以无线方式将无线设备连接到路由器。 然后，无线设备可以通过混合路由器与有线设备通信。

如果要将四个以上的有线设备联网，则可以雏菊链形状将多个路由器（有线和无线）串联在一起。 你需要足够的有线路由器来连接所有有线设备（设备数除以四）。 而且需要在正确的物理位置安装足够多的无线路由器，以便将 Wi-Fi 信号广播到网络的每个角落。 通过这种方式，可以连接计算机和外围设备（如打印机和传真机），并将其放置在易于使用的位置。

混合有线/Wi-Fi 网络两者相得益彰：有线网络的速度和安全性，以及无线网络的移动性和可负担性。 如果工作需要最大 Internet 和文件共享速度，可以通过以太网电缆接入网络。 如果需要在办公室走廊中向同事演示流视频，可通过无线方式访问网络。 通过合理规划，小型企业可以通过最大化无线网络的覆盖范围而节省 CAT 5 电缆和路由器方面的花费。 而且，有了正确的加密和密码管理，网络的无线部分可以像有线一样安全。

## 在网络上共享文件和文件夹

设置网络后，可能需要为工作和设备添加更多共享选项。 这些选项中的一部分可以自动进行设置，而其他可以进行手动设置。

适用于设备的共享选项包括：

- 查找家庭网络上的其他设备并让其他设备找到你的设备
- 共享文件和文件夹
- 共享公共文件夹

### 自动打开的共享选项

在 Windows 8.1 和 Windows 8 中，首次连接到网络时，系统将询问你是否要启用共享并基于你的选择设置网络位置。

#### 需要手动打开的共享选项

如果某些共享选项未自动开启，则可以手动激活它们。 这些手动激活选项包括：

- 网络发现
- 网络共享（以前的位置）
- 打印机共享
- 文件共享

### 网络发现

网络发现是一种网络设置，可让你的设备查找网络上的其他设备，并让其他设备查找你的设备。 通过此类功能，可以更轻松地共享文件和打印机。

网络发现状态有三种：

- **打开：**使你的设备能够查看其他网络设备，并使其他网络设备上的用户能够查看你的设备。
- **关闭**：阻止你的设备查看其他网络设备，并阻止其他网络设备上的用户查看你的设备。
- **自定义**：启用有限的网络发现。 例如，如果在不满足所有必需的防火墙条件的情况下运行网络发现，则网络发现状态将显示为“自定义”。

要手动激活网络发现，请按照说明操作。

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或单击“搜索”。
3. 在“搜索”框中，键入“网络和共享中心”。
4. 点击或单击“设置”。
5. 点击或单击屏幕左侧的“网络和共享中心”。
6. 点击或单击左窗格上的“更改高级共享设置”。
7. 点击或单击 V 形按钮以展开当前网络配置文件。
8. 点击或单击“启用网络发现”，然后点击或单击“保存更改”。

   注意

   系统可能会要求你输入管理员密码或确认你的选择。

### 网络共享（以前的网络位置）

网络共享会根据连接到设备的网络类型自动调整安全和其他设置。 若要检查网络共享是否启用，请按照以下说明进行操作。

首次连接至网络后，系统会询问你是否想启用设备之间的共享并连接到打印机等网络设备。 你的应答将自动针对网络类型设置合适的防火墙和安全设置。 你可以随时启用或停用共享功能。

##### 在 Windows 8.1 和 Windows 8 中启用或停用共享

1. 从屏幕右边缘滑入（如果你使用的是鼠标，请指向屏幕右上角，向下移动鼠标指针）。
2. 点击或单击“设置”。
3. 点击或单击“网络”图标。
4. 长按或右键单击网络名称。
5. 点击或单击“启用或停用共享”。
6. 选择以下任一选项：  
   **“是，启用共享并连接到设备。”** 针对家庭或小型办公网络或网络上你认识和信任的人员和设备使用此选项。  
   **“否，不启用共享或连接到设备。”** 针对公共场所（如咖啡店或机场）或网络上你不认识或信任的人员和设备使用此选项。

注意

- 网络共享仅对 Wi-Fi、以太网、VPN（非域）和拨号（非域）连接可用。 对于域网络不可用。 在 VPN 或拨号连接上，必须先连接到网络，然后长按或右键单击网络名称。
- 打开共享会更改防火墙设置，以启用某些通信，这可能会带来安全风险。 如果知道无需共享文件或打印机，最安全的选择是“否，不共享或连接到设备”。
- **选择“否”，请勿打开共享或连接到设备**，阻止以下应用和服务正常工作：
  1. PlayTo
  2. 文件共享
  3. 网络发现
  4. 自动设置网络设备

1. 单击“启动”。
2. 单击“控制面板”。
3. 单击“网络连接”。
4. 选择网络的网络连接。
5. 如果所使用的设备未显示，请选中“适用于 Microsoft 网络的文件和打印机共享”复选框。
6. 单击**关闭**。

   注意

   Windows XP 仅检测和访问同一工作组中的设备。

### 打印机共享

要手动激活打印机共享，请按照说明操作。

1. 打开“打印机和传真”控制面板，然后右键单击打印机。
2. 单击“共享此打印机”，然后单击“确定”。

注意

如果网络由运行类似硬件和软件的设备组成，则可以选择在主机系统上下载其他打印机驱动程序的选项。 如果网络为混合网络且包含多个 32 位和 64 位操作系统组合，则不建议选择此选项。

### 共享文件或文件夹

要共享文件或文件夹，请按照说明操作。

1. 单击“共享和安全”。
2. 选择要与之共享的用户或组。 你还可以分配权限，以便这些用户可以或不能更改为你共享的文件或文件夹。

注意

如果网络包含运行不同版本 Windows 的设备，请将所有设备放在同一工作组中。 这样，运行不同版本 Windows 的设备就可以互相检测和访问。 请记住，默认工作组名称在所有版本的 Windows 中都不相同。

### 受密码保护的共享

通过受密码保护的共享，网络上的用户无法访问其他设备（包括公用文件夹）上的共享文件夹，除非他们在设备上具有共享文件夹的用户名和密码。

在 Windows XP 中，默认情况下会开启受密码保护的共享。

### 网络映射

网络映射是网络上设备的图形视图。 映射显示设备的连接方式以及任何问题区域。 它有助于故障排除。

如果希望运行 Windows XP 的设备显示在网络映射上，则可能需要在该设备上安装链路层拓扑发现 (LLTD) 协议。

如果在安装 LLTD 协议后，Windows XP 设备仍未显示在网络映射上，请检查 Windows 防火墙设置，并确保已启用文件和打印机共享。 “要详细了解此问题，请打开‘帮助和支持’，然后搜索‘启用文件和打印机共享’”。 如果使用另一个防火墙，请参阅该防火墙中包含的信息。
