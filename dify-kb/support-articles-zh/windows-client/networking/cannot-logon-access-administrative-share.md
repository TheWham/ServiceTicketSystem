# 尝试从属于工作组成员的另一台基于 Windows 的计算机访问基于 Windows 的计算机上的管理共享时出错：登录失败：Windows 无法登录

本文介绍尝试从工作组成员的另一台基于 Windows 的计算机访问基于 Windows 的计算机上的管理共享时，登录失败的行为。

*原始 KB 数：* 947232

## 错误消息说明

假设出现了下面这种情景：

- 你在属于工作组成员的基于 Windows 的计算机上工作。
- 在此计算机上，你尝试访问位于另一台基于 Windows 的计算机的管理共享。
- 您尝试访问的计算机是工作组的成员或域的成员。 例如，尝试访问 C$ 管理共享。
- 系统提示输入用户凭据时，请在目标计算机上提供管理用户帐户的用户凭据。

在这种情况下，会收到以下错误消息：

> 登录失败：  
> Windows 无法登录。  
> 确保用户名和密码正确。

如果尝试使用 Net Use 命令将网络驱动器映射到管理共享，请在提供正确的凭据后收到以下错误消息：

> 系统错误 5  
> 。 拒绝访问。

## 原因

默认情况下，Windows 会阻止本地帐户通过网络访问管理共享。

## 解决方法

若要让用户具有访问权限，建议使用适当的权限在基于 Windows 的计算机上创建共享。 如果出于某种原因，无法应用此解决方法，建议尝试解决方法。

若要在启用了文件共享的基于 Windows 的计算机上共享文件夹，请执行以下步骤：

1. 单击“**启动>计算机”。**
2. 找到要共享的文件夹。
3. 右键单击要共享的文件夹，然后单击“ **共享**”。
4. 如果已启用受密码保护的共享，请选择哪些用户可以访问共享文件夹及其权限级别。 若要让所有用户都有权访问，请在 **用户列表中选择“每个人** ”。 默认情况下，权限级别为“读取者”。具有此权限级别的用户无法更改文件或在共享中创建新文件。 若要让用户更改文件、更改文件夹、创建新文件以及创建新文件夹，请使用“共同所有者”权限级别。

   如果禁用了受密码保护的 **共享，请选择“来宾** 帐户”或“ **每个人** ”帐户。 这与 Windows XP 中的简单共享相同。
5. 单击“**完成**共享**>**”。

## 解决方法

若要允许 Windows 工作组中的管理共享访问权限，请使用以下解决方法。

重要

此部分（或称方法或任务）介绍了修改注册表的步骤。 但是，注册表修改不当可能会出现严重问题。 因此，按以下步骤操作时请务必谨慎。 作为额外保护措施，请在修改注册表之前先将其备份。 如果之后出现问题，您就可以还原注册表。 有关如何备份和还原注册表的详细信息，请单击下面的文章编号，查看相应的 Microsoft 知识库文章：

[322756](https://support.microsoft.com/help/322756) 如何备份和还原 Windows 中的注册表

1. 单击“开始”**，在“开始搜索**”框中键入 regedit*，然后按 Enter。*****

   注意

   如果系统提示需要管理员密码或确认，请键入密码或进行确认。
2. 找到并单击下面的注册表子项：

   `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System`
3. 在 **“编辑** ”菜单上，指向 **“新建**”，然后单击 **“DWORD”（32 位）值**。
4. 键入 LocalAccountTokenFilterPolicy 以命名新条目，然后按 Enter。
5. 右键单击 **LocalAccountTokenFilterPolicy**，然后单击“ **修改**”。
6. 在“**数值数据**”框中，键入 *1*，然后单击“**确定**”。
7. 退出注册表编辑器。

注册表中的 LocalAccountTokenFilterPolicy 条目的值可以为 0 或 1。 这些值设置条目的行为，如下所示：

- 0 = 生成筛选令牌

这是默认值。 删除管理员凭据。 这些凭据是打印驱动程序的远程管理所必需的。

- 1 = 生成提升的令牌

此值允许在工作组中的服务器上远程管理打印驱动程序。

## 详细信息

如果基于 Windows 的目标计算机和要从中访问管理共享的计算机位于同一域中，则可以使用域管理员凭据访问共享。

如果基于 Windows 的目标计算机已加入域，并且你尝试使用已加入工作组的计算机连接到该域，则无法访问此管理共享。 即使为目标计算机所在的域提供正确的域管理员凭据，也是如此。

有关如何在 Windows Vista 中共享文件夹或打印机的详细信息，请访问以下Microsoft网站：

[Windows Vista 中的文件和打印机共享](/zh-cn/previous-versions/windows/it-pro/windows-vista/bb727037(v=technet.10))
