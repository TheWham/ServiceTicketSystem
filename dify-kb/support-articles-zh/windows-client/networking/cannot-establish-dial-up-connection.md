# 尝试建立拨号连接时出错：错误 734：PPP 链接控制协议已终止

本文有助于修复 **错误 734：尝试建立拨号连接时，PPP 链接控制协议已** 终止的问题。

*适用于：* Windows 2000  
*原始 KB 数：* 318718

## 现象

如果尝试建立点到点协议（PPP）拨号连接，可能会收到以下错误消息：

> 错误 734：PPP 链接控制协议已终止。

因此，无法建立拨号连接。

## 原因

如果满足以下任一条件，则可能会出现此问题：

- 为单链接连接启用了多链接协商。
- 拨号连接安全配置未正确配置为使用 **“需要安全密码** ”设置。

## 解决方法

若要解决此问题，请执行下列操作：

1. 单击“开始”**，指向**“设置”**，然后单击“网络”和“**拨号连接**”。**

   注意

   对于 Windows Server 2003，请单击“开始**”**，指向**控制面板**，然后指向**“网络连接**”。
2. 右键单击相应的拨号网络连接，然后单击“ **属性**”。
3. **单击“网络**”选项卡，然后单击“**设置**”。
4. 单击此项可清除 **“单链接连接的** 协商多链接”复选框（如果已选中）。
5. 单击“**确定**>**”。**
6. 双击连接，然后单击“ **拨号**”。

   - 如果此过程解决了该问题，并且可以建立拨号连接，则无需遵循本文中的剩余步骤。
   - 如果此问题无法解决问题，并且无法建立拨号连接，请转到步骤 7 继续排查此问题。
7. 右键单击连接，然后单击“ **属性**”。
8. 单击“安全”选项卡。
9. 在“安全”选项**下，单击“验证身份”**框中的“**允许不安全的密码**”，然后单击“**确定**”。
10. 双击连接，然后单击“拨号**”**以验证是否可以建立拨号连接。
