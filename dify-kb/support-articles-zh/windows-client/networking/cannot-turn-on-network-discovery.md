# 无法在网络和共享中心启用网络发现

针对无法在网络和共享中心启用网络发现的问题，本文提供了解决方法。

*原始 KB 数：* 2722035

## 现象

你尝试在运行 Windows Server 2012 的计算机上启用网络发现。 为此，你更改了“网络和共享中心”中的高级共享设置。 但是，未能保存这些更改。 因此，无法启用网络发现。 并且你遇到以下问题：

- 无法浏览或查找任何网络共享。
- 无法在本地网络上查看共享文件夹。

## 原因

此问题由以下原因之一导致：

- 网络发现的依赖项服务未运行。
- Windows 防火墙或其他防火墙不允许网络发现。

## 解决方法

若要解决该问题，请执行以下步骤：

1. 确保启动以下依赖项服务：

   - DNS 客户端的运行情况
   - “功能发现资源发布”
   - “SSDP 发现”
   - “UPnP 设备主机”
2. 按照以下步骤将 Windows 防火墙配置为允许网络发现：

   1. 打开“控制面板”，依次选择“系统和安全”和“Windows 防火墙”。
   2. 在左窗格中，选择“允许应用或功能通过 Windows 防火墙”。
   3. 选择“更改设置”。 如果系统提示你输入管理员密码或进行确认，请输入密码或进行确认。
   4. 选择“网络发现”，然后选择“确定”。
3. 配置网络中的其他防火墙以允许网络发现。
4. 在**网络和共享中心**启用**网络发现**。
