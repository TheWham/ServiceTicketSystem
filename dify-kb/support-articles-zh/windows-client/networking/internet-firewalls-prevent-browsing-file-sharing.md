# Internet 防火墙可以阻止浏览和文件共享

打开防火墙可能会阻止你搜索文件或与主网络上的其他计算机共享文件。

*原始 KB 数：* 298804

## 现象

启用 Internet 防火墙后，可能无法在家庭或办公室网络上搜索或浏览其他计算机。 并且你可能无法与家庭或办公室网络上的其他计算机共享文件。 例如，在 Windows XP 中启用 Internet 连接防火墙（ICF）功能时，你会发现无法使用“我的网络位置”浏览网络。 此外，如果使用 `net view \\computername` 命令查看家庭或办公室网络上的计算机上的共享，可能会收到以下错误消息：

> 系统错误 6118 已发生。 此工作组的服务器列表当前不可用。

## 原因

如果在用于家庭或办公室网络的网络连接上启用防火墙，则可能会发生此行为。 默认情况下，防火墙关闭用于文件和打印共享的端口。 目的是防止 Internet 计算机连接到计算机上的文件和打印共享。

## 解决方法

若要解决此行为，请仅对用于直接连接到 Internet 的网络连接使用防火墙。 例如，在通过电缆调制解调器、DSL 调制解调器或拨号调制解调器直接连接到 Internet 的单台计算机上使用防火墙。 如果使用同一网络连接连接到 Internet 和家庭或办公室网络，请使用路由器或防火墙来阻止 Internet 计算机连接到家庭或办公室计算机上的共享资源。

请勿在用于连接到家庭或办公室网络的网络连接上使用防火墙，除非可以将防火墙配置为仅为家庭或办公室网络打开端口。 如果使用家庭或办公室网络连接到 Internet，则防火墙只能在计算机或其他设备（如路由器）上使用，该路由器提供与 Internet 的连接。 例如，如果通过所管理的网络连接到 Internet，并且该网络使用连接共享提供对多台计算机的 Internet 访问，则只能在共享 Internet 连接上安装或启用防火墙。 如果通过不管理的网络连接到 Internet，请验证网络管理员是否正在使用防火墙。

## Status

此行为是特意这样设计的。

## 详细信息

防火墙是软件或硬件，在计算机之间创建保护屏障，并可能损害 Internet 上的内容。 它有助于保护计算机免受恶意用户和许多计算机病毒和蠕虫的攻击。

重要

如果设置了防火墙来帮助保护连接到 Internet 的计算机端口，我们建议你打开这些端口，因为它们可以公开给 Internet 上的其他计算机。 此外，无法向特定计算机授予对开放端口的访问权限。

以下端口与文件共享和服务器消息块（SMB）通信相关联：

- Microsoft文件共享 SMB：用户数据报协议（UDP）端口从 135 到 139，传输控制协议 （TCP） 端口从 135 到 139。
- 没有网络基本输入/输出系统（NetBIOS）：端口 445（TCP 和 UDP）的直接托管 SMB 流量。

### Windows x64 版本的技术支持

硬件制造商为 Microsoft Windows x64 版本提供技术支持和帮助。 你的硬件制造商提供支持，因为你的硬件随附了 Windows x64 版本。 硬件制造商可能已使用唯一组件自定义 Windows x64 版本安装。 单独组件可能包括特定设备驱动程序，也可以包括可选设置以最大限度提高硬件性能。 如果需要 Windows x64 版本的技术帮助，Microsoft将提供合理的帮助。 但是，你可能需要直接与制造商联系。 制造商最有资格为他们在硬件上安装的软件提供支持。

有关详细信息，请参阅保护 [电脑免受病毒的](https://support.microsoft.com/help/17228/windows-protect-my-pc-from-viruses)侵害。
