# 重新添加路由和远程访问接口后，默认网关路由不会显示在路由表中

本文提供了一个解决方案，用于解决默认网关路由未显示在路由表中的问题。

*适用于：* Windows Server - 所有版本  
*原始 KB 数：* 816905

## 现象

将网络接口添加到路由和远程访问实用工具中的远程访问服务器时，该接口的默认路由可能不会显示在路由表中。

## 原因

如果满足以下两个条件，则可能会出现此问题：

- 从远程访问服务器中删除网络接口。
- 将该网络接口重新添加到远程访问服务器。

要解决此问题，请使用下列方法之一。

## 解决方法 1：手动添加接口的默认路由

使用“路由添加”命令手动为添加的网络接口添加默认路由。

1. 单击“**开始”，单击“运行**”**，在***“打开****”框中键入 cmd*，然后单击“**确定**”。**
2. 键入路由打印，然后按 Enter 查看路由表。 请注意重新添加的网络接口的接口号。
3. 键入以下命令，然后按 Enter 路由添加 0.0.0.0 掩码 0.0.0.0 **网关 IP** 指标 **30** （如果 **接口编号）**  
   其中，网关 IP 是此接口的默认网关的 IP **地址，其中****接口号**是对应于所添加网络接口的数字（例如 2）。 例如，如果默认网关 IP 地址为 192.168.1.1，并且接口号为 2，请键入以下命令，然后按 Enter：

   ```
   route add 0.0.0.0 mask 0.0.0.0 192.168.1.1 metric 30 if 2
   ```
4. 键入路由打印以验证新的默认路由是否出现在路由表中。
5. 关闭命令提示符。

## 解决方法 2：重启远程访问服务

重启远程访问服务。 重新添加网络接口的默认路由将添加到 Windows 路由表中。

1. 启动路由和远程访问实用工具。
2. 在“路由和远程访问**”下**，右键单击重新添加网络接口的服务器，指向**“所有任务**”，然后单击“**重启**”。

## 解决方法 3：重启服务器

重启远程访问服务器。 重新添加网络接口的默认路由将添加到 Windows 路由表中。
