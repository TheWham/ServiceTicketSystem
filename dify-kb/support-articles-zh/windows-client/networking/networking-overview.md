# Windows 客户端网络故障排除文档

本节中的主题提供解决方案和方案指南，可帮助你排查和自行解决与网络相关的问题。 这些主题分为子类别。 浏览内容或使用搜索功能查找相关内容。

## 网络子类别

- 访问远程文件共享（SMB 或 DFS 命名空间）
- DNS
- 动态主机配置协议 (DHCP)
- 文件夹重定向和脱机文件和文件夹 （CSC）
- IP 地址管理 (IPAM)
- 远程访问
- TCP/IP 通信
- Web 应用程序代理（WAP）角色服务
- WebClient 和 WebDAV
- Windows Defender漏洞防护
- 具有高级安全性的 Windows 防火墙（WFAS）
- 无线网络和 802.1X 身份验证
