# Windows 10 和 Windows 11 的活动和已停用疑难解答

本文提供 Windows 10 和 Windows 11 的活动和已停用疑难解答列表，包括每个疑难解答的功能说明、所解决的问题以及适用的设备。要了解有关疑难解答的更多信息，请参阅[通过建议的疑难解答保持设备平稳运行](https://support.microsoft.com/help/4487232/)。

## 适用于从 Windows 10 升级到 Windows 11 的设备的 ELAN 指纹驱动程序疑难解答

**设置**中显示的文本：  
该疑难解答执行 `sfc /scannow` 命令。此命令修复损坏的 *onnxruntime.dll* 文件，使其与设备当前运行的 Windows 内部版本匹配。

### 说明

一些从 Windows 10 升级、现在运行 Windows 11 版本 21H2（OS 内部版本 22000）或更高版本的用户计算机，如果配备使用某些 ELAN 指纹驱动程序的指纹传感器，在使用依赖相关 DLL 的应用程序时可能会遇到故障或崩溃。

此疑难解答会在满足以下条件的设备上自动运行：

- 运行 Windows 桌面操作系统。
- 运行 Windows 11 版本 21H2（OS 内部版本 22000）或更高版本。
- *onnxruntime.dll* 文件没有版本号，或版本号为 0.0.0.0。
- ELAN 指纹驱动程序版本为 3.10.11001.10606、3.10.11001.10502 或 3.10.11001.10801。

|激活日期|停用日期|更多信息|
|---|---|---|
|2023/3/15|2025/4/12|[https://aka.ms/AAhdpvb](https://aka.ms/AAhdpvb)|

## 用于恢复对 M365 桌面应用程序访问的"访问工作或学校"疑难解答

**设置**中显示的文本：  
该疑难解答检查 `Microsoft.AAD.BrokerPlugin` 包是否缺失。如果缺失，则安装该包。

### 说明

某些用户无法登录 Microsoft 365 桌面应用程序。这包括：Teams、Outlook、OneDrive for Business、Excel、PowerPoint 和 Word。

此疑难解答会在满足以下条件的设备上自动运行：

- 运行 Windows 10 20H1
- Microsoft 365 企业版和专业版 SKU
- 缺少 `Microsoft.AAD.BrokerPlugin` 包

|激活日期|停用日期|更多信息|
|---|---|---|
|2022/8/24|2022/11/30|[https://aka.ms/AAhs34y](https://aka.ms/AAhs34y)|

## 用于修复 .NET Framework 组件的 Windows 更新疑难解答

**设置**中显示的文本：  
自动修复系统文件和设置以修复设备上的问题

### 说明

某些安装了 2022 年 4 月 25 日发布的 Windows 11 版本 21H2 更新 KB5012643 的设备无法运行 .NET Framework 应用程序。此疑难解答通过还原所需的 .NET Framework 组件来修复设备，恢复运行 .NET Framework 应用程序的能力。

此疑难解答会在满足以下条件的设备上自动运行：

- 运行 Windows 10 版本 21H2 和 Windows 11 版本 21H2
- 已检测到该问题

## 用于修复文件或元数据损坏的 Windows 更新疑难解答

**设置**中显示的文本：  
由于反复出现安装问题，自动将设备标记为进行就地升级

### 说明

某些运行 Windows 10 版本 1903 及更高版本的设备，由于服务堆栈内的文件或元数据损坏，无法安装月度安全更新。此疑难解答会标记该设备，为就地升级做准备。

此疑难解答会在满足以下条件的设备上自动运行：

- 运行以下操作系统之一：Windows 10 版本 1903、Windows 10 版本 1909、Windows 10 版本 2004 或 Windows 10 版本 20H2
- 运行的修订版本低于 2020 年 12 月安全更新（12B）
- 质量更新安装失败多次

|激活日期|停用日期|更多信息|
|---|---|---|
|2021/4/19|2025/10/30|[aka.ms/IPUTroubleshooter](https://aka.ms/IPUTroubleshooter)|

## 用于修复系统文件的 Windows 更新疑难解答

**设置**中显示的文本：  
自动修复系统文件和设置以提高设备安全性

### 说明

## "文件按需"疑难解答

**设置**中显示的文本：  
你可能已失去对"文件按需"的访问权限。此疑难解答会恢复访问权限，或防止在不久的将来失去访问权限。重要提示：疑难解答完成后请重启设备。

### 说明

在更新到 Windows 10 版本 2004 之后，某些较旧的设备，或者安装了某些使用旧版[文件系统筛选器驱动程序](/windows-hardware/drivers/ifs/about-file-system-filter-drivers)的旧版应用的设备，可能无法通过 OneDrive 应用连接到 OneDrive。受影响的设备可能无法下载新的"文件按需"内容，或无法打开之前同步或下载的文件。此疑难解答可缓解该问题。

成功运行"硬件和设备"疑难解答的设备会收到通知，并被要求运行此疑难解答。

|激活日期|停用日期|更多信息|
|---|---|---|
|2020/6/30|2020/9/30|[https://aka.ms/AA8vtwr](https://aka.ms/AA8vtwr)|

## 存储空间清理疑难解答

**设置**中显示的文本：  
自动还原你之前的存储空间设置和环境。

### 说明

在更新到 Windows 10 版本 2004（2020 年 5 月更新）或 Windows Server 版本 2004 之后，使用奇偶校验存储空间的设备可能无法使用或访问其存储空间。在你的设备应用 [KB4568831](https://support.microsoft.com/help/4568831) 之后，此疑难解答会还原你之前的存储空间设置。

此疑难解答会在满足以下条件的设备上自动运行：

已成功运行"硬件和设备"或"存储空间"疑难解答

## 存储空间疑难解答

**设置**中显示的文本：  
在你的奇偶校验存储空间上检测到数据损坏。此疑难解答会采取措施防止进一步损坏。如果该空间先前被标记为只读，它还会恢复写入访问权限。有关更多信息和建议的操作，请参阅下面的链接。

### 说明

使用奇偶校验存储空间的设备在更新到 Windows 10 版本 2004（2020 年 5 月更新）或 Windows Server 版本 2004 后，尝试使用或访问其存储空间时可能会遇到问题。此疑难解答可为部分用户缓解此问题，并恢复对奇偶校验存储空间的读取和写入访问权限。

此疑难解答会在满足以下条件的设备上自动运行：

已成功运行"硬件和设备"或"存储空间"疑难解答。

## 适用于奇偶校验存储空间的"硬件和设备"疑难解答

**设置**中显示的文本：  
自动更改系统设置以修复设备上的问题。

### 说明

使用奇偶校验存储空间的设备在更新到 Windows 10 版本 2004（2020 年 5 月更新）或 Windows Server 版本 2004 后，尝试使用或访问其存储空间时可能会遇到问题。此疑难解答有助于防止影响存储空间上数据的问题。疑难解答运行后，你将无法向存储空间写入数据。

此疑难解答会在满足以下条件的设备上运行两次：

- 运行 Windows 10 版本 2004
- 使用存储空间

第一次，疑难解答自动运行。第二次，它会通知用户。

## 用于磁盘清理的 Windows 更新疑难解答

**设置**中显示的文本：  
自动更改系统设置以修复设备上的问题。

### 说明

某些设备在安装 Windows 版本 19041.21 更新后运行磁盘清理时可能无法启动。此疑难解答会暂时禁用自动运行磁盘清理的功能，直到设备安装 Windows 10 版本 19041.84 更新。

此疑难解答自动运行两次。第一次在运行 Windows 10 版本 19041.21 的所有设备上运行。之后在设备升级到 Windows 10 版本 19041.84 后再次运行。  
  
|激活日期|停用日期|更多信息|
|---|---|---|
|2020/2/7|2020/11/28|[https://aka.ms/AA7afc1](https://aka.ms/AA7afc1)|

## Windows 登录疑难解答

**设置**中显示的文本：  
自动修复系统文件和设置以修复设备上的问题

### 说明

Windows 登录疑难解答通过修复损坏或丢失的资源文件来解决用户登录问题。它在资源文件损坏或丢失的计算机上自动运行，无法手动运行。要检查它是否已运行，在 Windows 10 中转到**开始** > **设置** > **更新和安全** > **疑难解答** > **查看疑难解答历史记录**，或在 Windows 11 中转到**开始** > **设置** > **系统** > **疑难解答** > **建议的疑难解答历史记录**，查找 **Windows 登录疑难解答**和**修复 Windows 登录问题**。

|---|---|---|
|2025/3/24||[https://aka.ms/AAv1efl](https://aka.ms/AAv1efl)|
