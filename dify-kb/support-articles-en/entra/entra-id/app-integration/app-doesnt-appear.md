# Application doesn't appear after clicking the add button

## Summary

The process of adding an application to Microsoft Entra ID may sometimes fail due to transient issues, networking problems, or a known issue. If you encounter an error when clicking the Add button, you’ll see a Notification in an Error state, which indicates that there was an error when creating the application. To learn more about the error or share it with a support engineer, you can follow the steps in [How to see the details of a portal notification](https://learn.microsoft.com/en-us/troubleshoot/entra/entra-id/app-integration/send-notification-details).
