# Microsoft Entra Hybrid Sync Agent Installation Issues

## Overview

The scenarios in this set of articles describe frequent issues when installing Microsoft Entra Hybrid Sync Agent, and how to correct them.

This troubleshooting doc applies to configuring the agent for [Microsoft Entra Connect cloud sync](/azure/active-directory/cloud-sync/how-to-install) or [Workday automatic user provisioning](/azure/active-directory/saas-apps/workday-inbound-tutorial).

- [No privileges to install MSI](https://learn.microsoft.com/en-us/troubleshoot/entra/entra-id/ad-dmn-services/azure-ad-hybrid-sync-no-privileges-install-msi)
- [Cannot start service AADConnectProvisioningAgent](https://learn.microsoft.com/en-us/troubleshoot/entra/entra-id/ad-dmn-services/azure-ad-hybrid-sync-cannot-start-aadconnect-provisioning-agent)
- [The gMSA is set to log on as Service](https://learn.microsoft.com/en-us/troubleshoot/entra/entra-id/ad-dmn-services/azure-ad-hybrid-sync-gmsa-set-logon-service)
- [There is no such object on the server](https://learn.microsoft.com/en-us/troubleshoot/entra/entra-id/ad-dmn-services/azure-ad-hybrid-sync-no-such-object-on-server)
- [Unable to create gMSA because KDS may not be running on domain controller](https://learn.microsoft.com/en-us/troubleshoot/entra/entra-id/ad-dmn-services/azure-ad-hybrid-sync-unable-create-gmsa-kds-domain-controller)

## Prerequisites

To install *Cloud Provisioning Agent*, the following prerequisites are required: [Prerequisites for Microsoft Entra Connect cloud sync](/azure/active-directory/cloud-sync/how-to-prerequisites).
