# Windows 电脑蓝屏（BSOD）排查指南

## 问题现象

电脑突然蓝屏并显示错误代码（如 `IRQL_NOT_LESS_OR_EQUAL`、`PAGE_FAULT_IN_NONPAGED_AREA`、`CRITICAL_PROCESS_DIED`、`DPC_WATCHDOG_VIOLATION` 等），随后自动重启；或反复蓝屏、开机即蓝屏。

## 快速自查（先做这几步）

1. **记录蓝屏代码**：蓝屏界面下方的"终止代码"（Stop Code），最好拍照留存。
2. **回忆近期变更**：是否刚装过软件、驱动、系统更新，或接过新硬件（U盘除外的新设备）。约 70% 的反复蓝屏与驱动/新硬件有关。
3. **断开外设**：拔掉除键盘、鼠标外的所有外接设备（U盘、移动硬盘、扩展坞、打印机等），重启观察。
4. **确认散热**：机身是否明显发烫、风扇是否异响，清灰并保证出风口畅通。

## 详细排查步骤

### 方法一：进入安全模式卸载问题驱动/软件

1. 强制关机 3 次（长按电源键），第 4 次开机会进入"自动修复"界面。
2. 选择「疑难解答 → 高级选项 → 启动设置 → 重启」，按 `4` 或 `F4` 进入安全模式。
3. 在安全模式中：
   - 打开「设置 → 应用」卸载最近安装的软件；
   - 右键开始菜单 →「设备管理器」，卸载或回退最近更新的驱动（尤其是显卡、网卡、存储驱动——右键设备 → 属性 → 驱动程序 → 回退驱动程序）。
4. 正常重启，观察是否还蓝屏。

### 方法二：修复系统文件

以管理员身份打开命令提示符（开始菜单搜索 `cmd` → 右键 → 以管理员身份运行），依次执行：

```
sfc /scannow
DISM /Online /Cleanup-Image /RestoreHealth
```

两条命令各需 5-15 分钟，执行完重启电脑。

### 方法三：检查内存

1. 按 `Win + R`，输入 `mdsched.exe`，回车。
2. 选择「立即重新启动并检查问题」。
3. 检测完成后自动重启，若报内存错误，基本可判定内存条故障，转硬件处理。

### 方法四：检查磁盘健康

管理员命令提示符执行：

```
chkdsk C: /f /r
```

提示下次重启检查则输入 `Y`，重启后自动检测（时间较长，请耐心等待）。

### 方法五：分析蓝屏转储文件（进阶）

1. 蓝屏会在 `C:\Windows\Minidump` 留下 `.dmp` 文件。
2. 可用微软官方工具 WinDbg Preview（微软商店免费下载）打开并运行 `!analyze -v`，定位到具体驱动文件（`.sys` 后缀）。
3. 不熟悉可跳过此步，直接把 `C:\Windows\Minidump` 整个文件夹打包提交给 IT 支持。

### 方法六：卸载最近的系统更新

「设置 → Windows 更新 → 更新历史记录 → 卸载更新」，卸载最近安装的补丁后重启。

### 方法七：系统还原 / 重置此电脑（最后手段）

- 有还原点：「控制面板 → 恢复 → 打开系统还原」回到蓝屏出现之前的时间点。
- 无还原点：「设置 → 系统 → 恢复 → 重置此电脑 → 保留我的文件」。**执行前务必备份数据。**

## 常见蓝屏代码对照

| 终止代码 | 常见原因 | 优先尝试 |
|---|---|---|
| IRQL_NOT_LESS_OR_EQUAL (0x0A) | 驱动、内存故障 | 方法一、三 |
| PAGE_FAULT_IN_NONPAGED_AREA (0x50) | 内存、坏驱动、磁盘坏道 | 方法一、三、四 |
| CRITICAL_PROCESS_DIED (0xEF) | 系统文件损坏 | 方法二、六 |
| DPC_WATCHDOG_VIOLATION (0x133) | 存储/SSD 驱动（常见于 SATA/NVMe 驱动不兼容） | 方法一（回退存储驱动） |
| SYSTEM_THREAD_EXCEPTION_NOT_HANDLED (0x7E) | 驱动冲突，注意括号内的 .sys 文件名 | 方法一、五 |
| KERNEL_SECURITY_CHECK_FAILURE (0x139) | 内存、驱动、系统文件 | 方法二、三 |
| VIDEO_TDR_FAILURE (0x116) | 显卡驱动 | 方法一（重装显卡驱动） |

## 转人工时请提供

- 蓝屏终止代码（照片最佳）；
- `C:\Windows\Minidump` 文件夹打包；
- 蓝屏发生场景（开机时/运行某软件时/随机）；
- 近期软硬件变更记录。

## 何时立即停止自行操作

- 蓝屏代码为 `CRITICAL_` 且伴随异响、焦味 → 立即断电，联系 IT。
- 硬盘发出咔哒异响 → 不要再反复重启，优先保数据。
