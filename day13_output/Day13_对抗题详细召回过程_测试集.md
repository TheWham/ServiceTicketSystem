# Day13 · 对抗题详细召回过程报告（测试集（封存，定稿后只运行一次））

**检索架构**：父子切片（Small-to-Big）。子块（512字符行累加）做向量/关键词精确匹配，
命中后经 `expand_to_parents` 回溯父块（整卡全文）返回。精排模型：qwen3-reranker-8b，精排粒度：父块级（子块召回后对整卡打分）。

> 说明：每题展示四阶段——① Dense 子块召回 ② BM25 子块召回 ③ RRF 融合 ④ Rerank精排+按秩融合，
> 卡片 id 前的 `→` 表示“命中子块后回溯到的父块”。
