# 【HW-001】电脑无法开机（黑屏、无任何反应）

> 所属分类：硬件与外设故障

**检索关键词**：无法开机, 黑屏, 电源灯不亮, 按开机键没反应, 充电指示灯, 适配器

## 现象描述

- 按下电源键后电脑完全无反应——电源指示灯不亮、风扇不转、屏幕无任何显示。或电源灯亮但屏幕黑屏，键盘灯亮但无显示输出。

## 常见根因

- ① 电源适配器故障或电源线松动（笔记本）
- ② 电池完全耗尽且适配器未供电（笔记本）
- ③ 内存条松动（常见于台式机搬运后）
- ④ 主板故障或静电保护
- ⑤ 显示器信号线松动或显示器故障（台式机）
- ⑥ 电源插座无电

## 员工自助排查

- 步骤1：检查电源插座是否有电（换其他电器测试）。
- 步骤2：检查电源适配器指示灯是否亮起（笔记本），重新插拔两端接口。
- 步骤3：笔记本：拔掉所有外接设备（鼠标、U盘、外接显示器），长按电源键15秒后松开，再正常开机。
- 步骤4：台式机：检查主机与显示器的视频线是否插紧，显示器是否选了正确输入源。
- 步骤5：台式机：断电后打开机箱，重新插拔内存条。
- 步骤6：尝试外接显示器（笔记本）判断是屏幕问题还是主机问题。

## IT工程师进阶处理

- 1. 用万用表测试电源适配器输出电压是否正常。
- 2. 更换已知正常的适配器/电源线/电池交叉测试。
- 3. 最小系统法：只保留CPU+单根内存+主板+电源，看能否点亮。
- 4. 清理内存金手指（橡皮擦拭），更换内存插槽测试。
- 5. 检查主板电容是否鼓包或漏液。
- 6. 如确认为主板/CPU故障，纳入硬件报修流程。
