# 【NET-002】有线网络无法连接（网口无反应）

> 所属分类：网络连接问题

**检索关键词**：有线网络, 网线, 以太网, 局域网, LAN, 插上网线没反应, 网络电缆被拔出

## 现象描述

- 插入网线后，电脑右下角网络图标显示红叉，或提示「网络电缆被拔出」「未识别的网络」「无Internet访问」。常见于：工位调整后、桌面整理后、雷雨天气后。

## 常见根因

- ① 网线物理损坏（折断、接口松动、水晶头氧化）
- ② 工位网口模块故障或配线架端口松动
- ③ 交换机端口故障或端口被管理员shutdown
- ④ 网卡驱动异常或被禁用
- ⑤ IP/MAC绑定导致新位置无法获取IP
- ⑥ VLAN配置错误，端口VLAN与用户VLAN不一致

## 员工自助排查

- 步骤1：重新插拔网线两端（电脑端 + 墙上面板端），听「咔嗒」声确认插紧。
- 步骤2：观察网口指示灯是否亮起（绿灯常亮=链路正常，绿灯闪烁=有数据传输，不亮=物理不通）。
- 步骤3：换一根已知正常的网线测试——如果换了就好，说明原网线损坏。
- 步骤4：换到隔壁工位网口测试——如果隔壁能上网，说明是你工位面板或对应交换机端口的问题。
- 步骤5：Win+R → ncpa.cpl → 右键以太网 → 禁用 → 再启用。
- 步骤6：重启电脑。

## IT工程师进阶处理

- 1. 用网线测试仪检测网线通断（1-8号线序）。
- 2. 登录交换机查看端口状态（show interface status），检查是否err-disabled或admin down。
- 3. 查看端口MAC地址表、VLAN配置是否正确。
- 4. 用打线刀重新压接配线架对应端口。
- 5. 检查DHCP服务器日志，确认是否有该MAC的租约记录。
- 6. 如怀疑交换机端口硬件故障，更换端口并更新配线架标签。
