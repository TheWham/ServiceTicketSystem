# 【SYS-001】Windows蓝屏/频繁死机

> 所属分类：系统与软件故障

**检索关键词**：蓝屏, BSOD, 死机, 蓝屏代码, STOP错误, 系统崩溃, 自动重启, CRITICAL_PROCESS_DIED

## 现象描述

- 电脑在使用过程中突然蓝屏，显示错误代码（如 CRITICAL_PROCESS_DIED、MEMORY_MANAGEMENT、DRIVER_IRQL_NOT_LESS_OR_EQUAL 等），随后自动重启。或电脑完全卡死，鼠标键盘无响应，只能长按电源键强制关机。

## 常见根因

- ① 内存故障（接触不良、金手指氧化、内存条损坏）
- ② 驱动程序不兼容（特别是显卡驱动、网卡驱动）
- ③ 系统文件损坏（不正常的关机导致）
- ④ 散热不良导致CPU/显卡过热保护
- ⑤ 硬盘坏道或SSD固件问题
- ⑥ 软件冲突（杀毒软件、系统优化工具）

## 员工自助排查

- 步骤1：重启电脑。如果频繁蓝屏，记录下蓝屏错误代码（拍照保存）。
- 步骤2：Win+R → 输入 mdsched.exe → 选择「立即重新启动并检查内存问题」进行内存诊断。
- 步骤3：检查电脑散热口是否被遮挡，风扇是否正常运转。
- 步骤4：Win+I → Windows更新 → 检查并安装所有待处理的更新。
- 步骤5：如果有最近安装的软件/驱动，尝试卸载后观察。
- 步骤6：Win+R → cmd（管理员） → sfc /scannow 扫描修复系统文件。

## IT工程师进阶处理

- 1. 使用 BlueScreenView 工具分析 dump 文件（C:\Windows\Minidump），定位导致蓝屏的驱动/模块。
- 2. 使用 MemTest86 进行深度内存检测（需制作启动U盘）。
- 3. 使用 CrystalDiskInfo 检查硬盘健康状态（SMART数据）。
- 4. 进入安全模式卸载可疑驱动/软件。
- 5. 检查系统事件查看器（eventvwr.msc）→ Windows日志 → 系统，筛选关键错误。
- 6. 如确认为硬件故障，协调更换内存/硬盘，或整机返修。
