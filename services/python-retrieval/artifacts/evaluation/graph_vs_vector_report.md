结合你描述的两个现象——**VPN 报错 691（认证失败）** + **手机企业邮箱提示凭据失效**，这两个问题同时出现，最可能的原因是：

## 最可能的原因

**你的 AD（域）账号被锁定，或密码已过期/被修改。**

理由：
- VPN 错误代码 **691 = 用户名或密码错误 / 认证被拒**，对应参考卡片 VPN-001 的根因③「用户名密码错误或AD账号被锁定」。
- 企业邮箱（企业微信/Exchange 等）同样使用 AD 账号认证，**同一个账号被锁定或密码失效时，邮箱也会提示凭据失效**。
- 两个系统同时报认证问题，基本可以排除"家庭网络防火墙阻断"这类网络原因（网络问题不会导致邮箱凭据失效）。

其他可能但概率较低的组合原因：
- 密码刚被修改，但 VPN 客户端和手机邮箱仍保存着旧密码。
- 账号被管理员禁用或企业认证过期（对应 MAIL-003 根因④）。

## 完整自查与解决流程

### 第一步：先验证账号本身是否正常（最关键）
1. 用电脑浏览器登录公司 **Web 邮箱 / OA / 企业微信网页版**，用你的 AD 账号密码登录。
   - 能登录 → 说明账号密码正常，问题在 VPN 客户端或手机端保存的旧凭据。
   - 不能登录，提示密码错误/账号锁定 → 基本确认是 **AD 账号被锁定或密码过期**，直接跳到第四步。

### 第二步：排查 VPN（错误 691）
2. 确认本地网络能正常上网（浏览器打开百度）。
3. 用**手机热点**连接测试：如果热点能连 VPN、家庭宽带不行，才是家庭网络问题；但结合邮箱现象，这里大概率不是网络问题。
4. 核对 VPN 客户端里的**服务器地址、用户名、密码、预共享密钥**是否与公司配置文档一致（VPN-001 步骤4）。
5. 重新输入一次密码（注意大小写、是否误开大写锁定），确认没有输错。
6. 若仍报 691，尝试切换 VPN 协议（如 L2TP → SSL VPN，SSL VPN 穿透性最好）。

### 第三步：排查手机企业邮箱
7. 在手机上**退出登录 → 彻底关闭 App → 重新打开登录**（MAIL-003 步骤3）。
8. 检查 App 是否为最新版本，必要时更新。
9. 关闭手机上的 VPN/代理后重试（VPN 可能干扰 IM/邮箱连接）。
10. 检查手机系统时间是否准确（时间偏差过大会导致认证失败）。

### 第四步：联系 IT / 自助重置（针对账号锁定）
11. 如果第一步网页登录也失败，说明是账号层面问题，需要：
    - 通过公司**自助密码重置平台**修改/重置密码；
    - 或联系 IT 解锁 AD 账号、确认密码是否过期。
12. 账号恢复后，**同步更新**：VPN 客户端密码、手机邮箱密码、企业微信密码（都改成新密码）。

### 第五步：若账号正常但仍连不上，交给 IT 进阶处理
- 检查 VPN 服务器状态（CPU/内存/并发连接数/带宽）。
- 检查边界防火墙是否放行 VPN 协议端口（UDP 500/4500、TCP 443）。
- 查看 VPN 服务器日志，定位具体拒绝原因。
- 检查 AD 账号状态（是否锁定、密码是否过期）。
- 推荐改用 **SSL VPN**（基于 HTTPS，穿透性最好，不易被酒店/家庭网络阻断）。

## 一句话结论
**优先怀疑 AD 账号被锁定或密码过期**——这是同时导致"VPN 691 认证失败"和"邮箱凭据失效"的最合理解释。请先用网页版邮箱验证账号能否登录，若不能则重置密码/联系 IT 解锁；若能登录，则重点检查 VPN 客户端和手机端保存的旧密码并重新输入。

**第一阶段：员工自助排查（先做，成本最低）**

1. **立即处理手机端邮箱**（切断锁定源头，最关键）：
   - 打开手机上的企业邮箱/邮件客户端，**退出登录或删除该账户**，避免旧密码继续轮询。
   - 若手机还装有企业微信、其他同步类App，一并检查是否保存了旧密码。

2. **等待自动解锁**：根据ACC-001步骤1，等待 **15-30分钟**，部分锁定策略会自动解除。

3. **检查键盘状态**：确认 **Caps Lock（大写锁定）** 和 **Num Lock** 未误开启，避免再次输错密码。

1. **解锁账户**：AD域控制器 → `Active Directory用户和计算机` → 找到该用户 → 属性 → 账户 → **解锁账户**（拓扑事实13）。

2. **定位锁定来源**：检查域控**安全日志**，筛选**事件ID 4740**（拓扑事实14、15），确认锁定来源的**IP和设备名**：
   - 若来源是用户自己的手机 → 确认是邮箱旧密码轮询，按第一阶段处理；
   - 若来源是**未知IP** → 可能涉及暴力破解（拓扑事实7），需**上报信息安全团队**。

3. **重置密码**：为用户重置密码，并勾选"**用户下次登录时须更改密码**"（拓扑事实16）。

4. **核查锁定策略**：检查组策略 → 计算机配置 → Windows设置 → 安全设置 → 账户策略 → **账户锁定策略**（拓扑事实17），确认锁定阈值与锁定时长是否合理。

5. **加固预防**：建议用户绑定手机/邮箱用于**自助解锁**，并统一更新所有终端（PC、手机、平板）的密码，杜绝旧密码轮询再次触发锁定。
