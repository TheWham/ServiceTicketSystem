# 混合检索与重排召回率对比评测报告

**所属项目**：企业 IT 常见问题知识库 RAG 检索基座工程
**实验日期**：2026-10-15
**知识库**：《IT常见问题RAG知识库.docx》→ 清洗重构的 35 张 Wiki 卡片 → 父子切片（Small-to-Big）
**测试引擎**：Chroma 向量数据库 + BM25Okapi 倒排索引 + RRF (k=60) + qwen3-reranker-8b (KSP /rerank，精排粒度：父块级（子块召回后对整卡打分）)
**评测集**：主题集　**构成**：14 道正样本 + 6 道负样本（7 道硬匹配 + 3 道同义改写 + 4 道近邻混淆 + 6 道库外负样本）
**综合最优链路**：链路 D：全链路+qwen3-reranker-8b（Recall@3 100.0%, MRR 1.00）

> **指标口径说明（四轨严格对齐父卡 Top-3）**：
> - **卡级 Recall@3**：四条链路均先取 `rough_top_k=15` 个候选子块，经 `expand_to_parents` 去重回溯后取前 3 张不重复的父卡，判断目标卡 `wiki_id` 是否进入 Top-3；
> - **MRR**：目标卡在去重父卡序列中的名次倒数均值；
> - **事实覆盖（限目标卡）**：黄金考点只在检索到的目标卡正文内计数，目标卡未召回记 0；
> - **负样本误召回**：库外问题若 Top-3 命中预设陷阱卡，记一次误召回；全链路低置信拒答（返回空）不算误召回；
> - **近邻混淆题**：query 字面贴近兄弟卡，额外报告兄弟卡在 Top-3 父卡中的名次。

## 四、 核心架构总结与技术承接

1. **双路召回的互补性（本轮数据）**：
   BM25 排第 1 而 Dense 未排第 1：HC-12（字面硬匹配补位）；Dense 排第 1 而 BM25 未排第 1：HC-08（语义对齐补位）。
2. **RRF 倒数排名融合的鲁棒性**：
   通过常数 $k=60$ 的倒数打分，无需调参即完美化解了余弦分（0~1）与 BM25 分（0~30+）异构打分冲突，多样性融合在事实分散题面上召回率领先。
3. **Cross-Encoder 精排的定位**：
   qwen3-reranker-8b 在正样本排序上与 RRF 打平（本库主题区分度高，RRF 已排对），其独有价值在于原始相关度分可用于**低置信拒答**：库外问题的最高分明显低于库内问题，按阈值 0.4 拒答后负样本误召回降至 0 / 6，而 Dense/BM25/RRF 只能给出名次、无法判断"像不像"，必然把最像的 3 张卡塞给 LLM。
4. **评测方法论沉淀**：
   本轮评测将四条链路严格对齐到“Top-15 粗排候选 → 父卡去重 Top-3”的同口径下比较，改用卡级 Recall@3 / MRR / 限目标卡事实覆盖 + 负样本误召回四项指标。
