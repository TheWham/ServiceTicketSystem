# IT 服务工单系统

Vue 3 前端，保留当前工单、咨询和知识管理服务协议。工作区使用连续列表、状态筛选、就地操作与侧边详情；支持浅色／深色、窄屏、键盘快速前往和减少动态效果。

界面采用暖灰与炭黑基础色、陶土橙单一强调色，配合细边框、终端式标识和少量等宽文字。浅色与深色主题共享同一配色体系；常规状态使用中性色，告警与错误保留必要的语义提示。

## 启动与服务连接

```sh
cd frontend
npm install
npm run dev
```

默认地址 `http://127.0.0.1:5175`，`/api` 代理到 `http://127.0.0.1:28080`，与本项目已有远端数据库服务启动配置一致。端口已占用时启动会明确失败，不会悄悄切换到其他端口。

其他部署环境可将 `.env.example` 复制成 `.env.local`，设置 `API_PROXY_TARGET` 后重启 Vite。此变量是后端网关地址，不是数据库连接地址。生产构建使用同源 `/api`，由部署服务器转发到相应网关。

排查旧账号时首先核对浏览器端口与代理目标：本机曾同时运行另一个目录的 `5173 → 8080` 服务，该接口返回旧版小写角色 `employee / engineer / supervisor`。当前项目只接受 `EMPLOYEE / ENGINEER / PLATFORM_ADMIN / KNOWLEDGE_ADMIN`；身份以登录接口或 `/users/me` 为准，不从旧 `mock_user` 缓存恢复权限。

2026-09-30 联调中，当前项目网关 `28080` 的登录选项曾返回 500，随后复查恢复为 200，返回 7 个账号及上述四种正式角色。前端保留明确的失败与重试状态，不会回退到旧服务。此次只修改前端，没有修改、重启或切换数据库及后端服务。

## 界面与组件

- `src/styles/workspace.css`：品牌、状态、双主题与响应式变量。
- `src/App.vue`：角色导航、通知、主题、离线提示和咨询入口。
- `src/components/WorkspaceSearch.vue`：采用 [shadcn-vue Dialog 组合模式](https://www.shadcn-vue.com/docs/components/dialog)，用 Reka UI 的模态、焦点与键盘基础实现快速前往。
- Element Plus 承载业务表单、列表和详情；图标按实际使用导入。
- 列表搜索按当前接口能力明确标注为“搜索本页”；不伪装成跨页检索。分类来自当前接口，生产代码没有演示记录。

## 验证

```sh
npm test
npm run build
npm run test:browser
```

浏览器测试使用真实 Chrome 渲染和交互，在网络边界隔离测试记录，避免写入实际账号、工单或知识库。测试记录只在 `tests/browser/`，不进入构建。截图、跟踪和运行报告保存在被忽略的 `test-results/`。

真实服务错误测试与隔离接口测试分别记录；后端不可用时，前端交互通过不代表真实数据库写入流程已验收。

2026-09-30 最终验证：149 项单元测试、45 项 Chrome 浏览器测试通过，生产构建成功。其中 44 项浏览器测试隔离 API，1 项只读检查真实登录选项（最终 HTTP 200，过程中曾观察到超时）。覆盖四类角色、详情与返回、补充信息、审核权限、101 条咨询消息、身份重验、中文输入法、主题、移动端键盘与网络异常。构建仍提示主包较大；本次已移除未使用页面和全量图标注册，未改动依赖框架。详细记录见本地 `test-results/workspace-browser-report.md`。
