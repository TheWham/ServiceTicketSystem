# 智能客服前端接入

**目标：** 员工可从导航和工作台进入 `/consultation`，使用现有咨询服务完成 AI 问答、反馈、转人工和跳转提单。

**设计：** 延续 Vue 3 / Element Plus 的蓝白与深色主题。独立页面采用服务说明侧栏与聊天主区域；欢迎态提供可编辑的常见问题；消息、引用、反馈与转人工复用 ConsultationChat。小屏改为单列。不增加依赖，不使用模拟回答作为实际服务回复。

**实施与验证：**
- [x] 接通员工路由、导航、工作台入口，保持其他角色的工作台导航。
- [x] 增加页面布局、欢迎问题、状态标题、输入说明和响应式样式。
- [x] 补齐初始化失败重试，中文输入法回车保护与失败草稿恢复。
- [x] 运行组件行为测试、完整前端测试与构建，并检查浏览器展示和关键交互。

**接口：** 使用 `frontend/src/api/consultation.js` 的 `/api/v1/consultations` 系列接口；沿用已有认证与请求幂等逻辑。AI 故障时显示真实错误，保留转人工与提交工单入口。

**验证记录：** 客服相关 23 项测试通过；完整套件 44 项中 24 项通过，20 项失败在 HEAD 基线中同样存在（账号契约、工单合并契约、SLA）。Vite 构建通过，保留已有大包体警告。浏览器使用接口桩验证快捷问题、中文输入、消息发送、引用、失败恢复、转人工、取消排队、新咨询、导航与亮暗主题/390px 窄屏。真实本地网关验证登录、创建咨询及 AI 请求：HTTP 200 / SUCCESS，但 AI 返回 REFUSE / MODEL_UNAVAILABLE；页面展示降级操作。本次创建的测试咨询已关闭。
