# 工单撤回及详情间距

目标：详情提供独立操作区，修正按钮紧贴卡片；用户可撤回自己的未结束工单，撤回后作废但保留存档，显示“已撤回”，本人和平台管理员可查看，工程师不可见。

方案：复用 CANCELLED 终态，新增 POST /tickets/{id}/withdraw，并让旧 cancel 操作走相同事务逻辑。撤回校验本人、非终态，保留内容、原负责人和附件，停止 SLA，结束未完成分派，写审计记录；撤回后不能编辑。列表在 SQL 分页之前过滤，详情、附件、SLA 同步限制撤回档案访问。原已完成/已关闭记录不能再次撤回。
