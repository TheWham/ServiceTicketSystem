# IT 服务台未来科技视觉改版

**目标：** 用户明确要求在已完成前端基础上再次增强未来科技感；本轮执行视觉修订，沿用已确认的功能、导航与页面结构。

**设计依据：** ui-ux-pro-max 的 Glassmorphism 与 HUD / Sci-Fi FUI 检索。采用深空蓝黑、青蓝光线、细网格、轨道图形和半透明导航；舍弃闪烁、故障特效、伪实时指标和影响正文阅读的装饰。浅色同步设计成银白冰蓝。

**技术：** Vue 3 + Element Plus；代码原生 SVG/CSS，无新增依赖；沿用用户保存的明暗偏好。

## 视觉规范

- 暗色页面 #060D19，面板 #0D1B2C，主文字 #E8F4FF，次级文字 #A1B6CF；青色 #67E8F9，蓝色 #78ADFF。
- 浅色页面 #EDF4FA，面板 #FFFFFF，主文字 #10273D，次级文字 #476176；深青 #08758C、主操作蓝 #245DCE。
- 数字与英文小标题使用本地等宽字体；中文保留系统无衬线字体。
- 装饰网格仅在空白区域显现；内容面板保持足够不透明度；边缘光线不改变按钮/表格布局。
- SVG 不承载业务状态，不把轨道装饰标为“在线”或真实系统指标。
- 仅导航与登录环境做受控模糊；避免大面积表格背景滤镜。移动端缩减装饰占位。
