# 知识队列直接展示标题

**目标：** 管理员在文章列表即可识别知识内容，不必逐条打开详情。

**实现：** 列表接口一次查询取文章当前版本的 title，不额外逐条请求详情，不返回正文。KnowledgeArticle 增加非持久化 title 字段；已有分页和筛选保留。首列展示标题、下方次要显示文章 ID，长标题换行，缺标题显示“（未命名知识）”。

- [x] 扩充列表查询并调整前端首列。
- [x] 后端测试、前端构建和浏览器展示验证。
- [x] 更新运行中的知识服务，使当前页面立即可用。

**联调发现：** 示例知识管理员的真实状态是 ACTIVE，但网关对 U_KBA01/kb_admin 返回硬编码的小写 active，导致浏览器所有管理请求被拒绝。移除该特例，统一查询用户服务；补充 ACTIVE 放行、DISABLED 拒绝回归测试，并更新网关运行包，保证列表能经正常登录访问。

**验证结果：** 知识服务 62 项通过（另 1 项可选 Redis 实测未启用），网关 8 项通过，前端相关 2 项与构建通过。真实管理员登录后浏览器展示 10 条列表标题、4 条待审核标题，无逐条详情请求；长标题换行及空标题回退验证通过。知识服务、网关已更新并重启。截图位于 `logs/knowledge-titles/queue.png`。
