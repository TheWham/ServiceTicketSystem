# AI 多轮上下文与通用 IT 回答实施计划

> **For agentic workers:** Use test-driven-development and verification-before-completion for each task; parallel workers have disjoint write scopes.

**Goal:** 当前 AI 会话支持连续追问；合法 IT/电脑问题可以由模型通用能力回答，不因检索相似度或模型自评分区间被拒答。

**Architecture:** 从已授权的当前会话加载有角色的、长度受限的 AI 对话历史，过滤撤回、人工聊天、系统消息及当前重复消息。生成模型依据完整会话判定范围和风险、追问或回答；检索只负责补充已发布知识，分数只决定可用引用。检索异常、伪造引用和未授权危险请求继续显式处理。

**Tech Stack:** Java 17+、Spring Boot、MyBatis Plus、JUnit 5、Mockito、JDK HttpServer。

## Global Constraints

- 用户已明确授权本计划的行为变更；在当前工作区实施，保留现有未提交改动，不提交密钥或用户其他工作。
- 上下文仅来自当前用户有权访问的当前 AI 会话；不读取其他会话、人工聊天或已撤回正文。
- 外部输入及历史均为数据，不提升为 system 指令；模型不执行系统操作、不编造公司内部事实。
- 未命中/弱命中不是服务故障；引用存在性、当前发布版本和输出协议校验继续有效。
- 使用本地 HTTP 固件测试模型协议，不依赖付费模型调用。
