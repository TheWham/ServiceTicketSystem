# 【项目名称】：IT 工单系统 Qwen3-4B-Instruct-2507 算力与基础设施定盘表

## 模型说明

Qwen3-4B-Instruct-2507 为 4B 参数级指令模型，适合 IT 工单、知识库检索后的简单问答和流程辅助。按 1,000 人企业规模估算，不按 1,000 人同时在线设计，建议按本地峰值 8–12 并发，并使用 API 处理突发流量。

## 一、业务并发与负载输入 (Input Baseline)

- 目标模型选型：[x] Qwen3-4B-Instruct-2507
- 权重精度格式：[ ] FP16 (2B)   [ ] FP8 (1B)   [x] INT4-AWQ (0.5B)
- 目标峰值并发 (Concurrency)：12（本地并发上限）
- 平均请求上下文长度 (Avg Context)：4,096 Tokens (含输入+输出)

## 二、显存精确预算推导 (Memory Budget)

1. 静态模型权重显存：约 2.5 GB
2. 动态 KV Cache 显存：约 4.5 GB（12 并发 × 4,096 Tokens × 单 Token 开销）
3. 系统激活与安全冗余 (×1.2)：约 3.8 GB

- **合计最低显存需求**：约 10.8 GB

## 三、硬件配置与拓扑定盘 (Hardware Proposal)

- 推荐加速芯片：[ ] NVIDIA A800 (80G)   [x] RTX 4090 (24G)   [ ] 昇腾 910B (64G)
- 所需芯片卡数：TP = 1 张卡
- 综合吞吐评估：预估单 Token 输出延迟 < 20–40 ms，吞吐峰值支持 200–350 Tokens/s
