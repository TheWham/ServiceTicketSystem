为了精准检验学员在 **第二阶段（知识库工程与业务 Agent）** 是否真正具备“企业级独立交付能力”，而不是仅仅停留在“跑通开源 Demo、抄写教程代码”的浅层水平，我们采用 **“场景穿刺式实战考核题 + 交付级验收 Checklist”**。

这套考题直击企业交付中最容易导致“线上翻车”的深水区（版本冲突、SQL 注入、网络震荡、人机审批、成本可观测性）。

# 🎯 第二阶段 FDE 核心能力考核考题与验收标准

## 【综合考核场景设定】

> **业务背景**：  
> 某制造企业（华科智造）上线“智能差旅合规审计与报销助手”，系统需同时读取企业的非结构化制度文档（规章、通报备忘录）、连接财务业务数据库（员工报销流水与账目），并能在发现超标时调用外部 OA 系统发起预警或追回审批。  
> 目前系统正在进行交付前的**压力盲测与安全提测**。

---

## 📝 考核核心问题（三维穿刺问答与实操）

### 维度一：知识库深水区（数据工程、版本消歧与置信度门禁）

**考核题目**：

> 1. 客户现场存在《差旅住宿规约 2024 新版》（2024-03-01 生效，一线总监 800 元/天）与《旧规及 Q1 审计备忘》（3 月前执行 600 元/天，违规需追回）。如果提问：  
>    *“王大明总监 2024 年 2 月在上海出差 2 天申报了 1800 元，应该如何处理？请给出法律/规章依据。”*  
>    **如果你的系统直接回答“符合 800 元标准因此合规”，工程根因是什么？你在数据清洗、切块（Chunking）和检索层应如何架构设计以保证 100% 避坑？**
> 2. 当用户提问包含特殊编码（如工号 `HK7991`、单号 `EXP20240220-03`）或未在制度中记载的生僻问题（如“能否用年金提前抵扣住宿发票？”）时，**你的检索管道如何兼顾专有名词的高命中率与超出知识库范围时的“确定性诚实拒答”？**

---

### 维度二：Agent 生产防线（安全 Text2SQL、弹性 API 与人机回环 HITL）

**考核题目**：

> 1. 大模型在根据自然语言生成 SQL 查询数据库时，**为什么只设置数据库只读账号依然远远不够？** 请详细阐述你的系统如何利用 **AST 语法树解析** 拦截诸如意图穿透攻击（`SELECT *; DROP TABLE...`）、多语句拼接、敏感表越权以及无 LIMIT 导致的笛卡尔积 DoS 攻击。
> 2. 当 Agent 调用外部 OA 审批接口遇到网络超时（Timeout）或 504 网关错误时，**你的代码是如何实现指数退避与抖动重试（Backoff + Jitter）的？如果工具多次报错，ReAct 循环如何通过 Error Reflection（错误回传自愈）避免陷入死循环？**
> 3. **人机回环（Human-in-the-Loop）真实落地机制**：当系统判定需要对员工执行“扣款 400 元并写入 ERP”这种高风险写操作时，**代码层面上如何让流程挂起（Suspend）、生成带签名的不可篡改审批凭证（Token）、等待人工在外部界面审批通过后，再精准恢复（Resume）执行状态？**

---

### 维度三：确定性编排与 APM 可观测性（成本核算与故障排查）

**考核题目**：

> 1. 为什么在严肃企业业务中坚决杜绝“无约束放飞的 AutoGPT/ReAct”，而必须采用 **Anthropic 确定性工作流（Workflow）**？请画出或阐述你当前系统的状态机主链路骨架。
> 2. 现场打开 **Langfuse APM 看板**（或本地追踪日志）：请指认一次端到端请求的 **Trace、Span 与 Generation 三级拓扑结构**，并明确回答：
>    * 本次交互的总时延是多少毫秒？耗时最长的木桶瓶颈在哪个节点？
>    * 输入与输出共消耗了多少 Token？折合本次请求的货币成本（USD/RMB）是多少？

## 📋 学员实操验收任务（现场代码与运行自检 Checklist）

要求学员在自己的工程环境中现场运行或调出代码，必须**当场通过以下 4 项断言自检**：

- [ ] **自检项 1（跨版本消歧断言）**：输入包含 2024 年 2 月份超标发票的单号，控制台输出必须准确引用旧规条文（600 元上限），并精准计算出应追回金额（400 元），不得误套 3 月 1 日新规（800 元）。
- [ ] **自检项 2（SQL 注入破坏测试）**：在问题中注入破坏指令（如 `EXP01; DROP TABLE tb_expense;` 或跨权限查薪资表），拦截器必须在 5 毫秒内通过 AST 抛出安全异常拦截，数据库连接未受污染。
- [ ] **自检项 3（HITL 状态机挂起）**：执行包含写操作的审批工作流，系统必须输出 `STATUS: SUSPENDED`，打印等待人工审批的临时 Token，且在未收到确认入参前严禁向外部 API 发起 POST 请求。
- [ ] **自检项 4（APM 成本大盘打印）**：单次任务结束后，终端必须打印出格式化的 Langfuse Trace 字典，清晰列出所有 Span 耗时列表及 `total_cost_usd`（格式精确到小数点后 5 位）。

> **判定结论**：  
> 若学员能条理清晰地回答上述 3 个维度的架构设计根因，并在终端无报错跑通上述 4 项 Checklist，即可证明其**第二阶段知识库与业务 Agent 体系已经学得非常扎实，具备独立承担企业级生产交付的技术实力**。
