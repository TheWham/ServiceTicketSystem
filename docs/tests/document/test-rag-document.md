# 企业网络与VPN故障排查及连接指南

本文档作为企业 IT 知识库标准操作指南，旨在指导员工在日常办公过程中，遇到内网 Wi-Fi 掉线、有线网络不通以及远程办公 VPN 认证失败时的标准排查与修复流程。

## 一、物理有线与无线网络基础排查

当电脑无法访问互联网或企业内网系统时，请按以下顺序进行基础检查：

1. **检查网线连接**：请确认网线水晶头已牢固插入电脑网口及墙面网络插孔，网卡指示灯（绿灯常亮、黄灯闪烁）处于正常闪烁状态。
2. **无线 Wi-Fi 重新认证**：
   - 断开名为 `Corp-Office-5G` 的无线网络，等待 5 秒后重新点击连接。
   - 输入企业域账号与当前最新的密码进行 802.1X 身份认证。
3. **刷新本地 DNS 缓存**：
   - Windows 用户可按下 `Win + R` 键，输入 `cmd` 打开命令行终端。
   - 执行命令：`ipconfig /flushdns` 并回车。
   - 再次执行 `ipconfig /renew` 重新向 DHCP 服务器获取局域网 IP 地址。

## 二、企业 VPN 客户端登录与证书异常处理

远程办公或出差期间连接内网系统必须启用企业专属 VPN 客户端（EasyConnect / GlobalProtect）。

### 2.1 常见错误代码与解决方案

* **错误 1001（用户认证失败）**：
  - 原因：域账号密码过期或输入错误。
  - 解决方法：访问员工自助门户 `https://sso.company.internal/reset` 修改密码后重新登录。
* **错误 2003（客户端安全证书无效或过期）**：
  - 原因：本地计算机存储的根证书未及时同步更新。
  - 解决方法：
    1. 打开 VPN 客户端设置面板，进入【高级选项】->【证书管理】。
    2. 点击【重新下载并导入根证书】。
    3. 重启 VPN 客户端后再次尝试连接。

### 2.2 VPN 隧道建立成功但无法打开内网网页

若客户端显示“已连接”，但浏览器仍无法打开内网系统（如工单系统、OA、代码仓库）：
- 请检查是否开启了第三方个人代理软件（如抓包工具、翻墙插件），请将其彻底退出。
- 检查本地路由表，在终端执行 `route print` 查看默认路由是否正确指向 VPN 虚拟网卡网关。

## 三、网络与 VPN 服务求助及提单规范

若经过上述步骤仍无法恢复连接，请收集以下信息并在 IT 服务台直接提交工单：
1. 故障发生时的具体错误弹窗截图。
2. 电脑当前的 IP 地址及 DNS 配置（可截图 `ipconfig /all` 输出结果）。
3. 您的办公地点（例如：北京研发中心 A 座 4 层 / 居家办公）。
