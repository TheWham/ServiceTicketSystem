👤 1. 员工

发起故障咨询、排查自愈验证、补全提单卡片、工单提交、完工验收与服务打分评价。

🤖 2. AI 客服

基于 RAG 检索知识库并生成排查方案；拦截 80% 常见故障实现自愈；无法自愈则打包上下文转人工。

🎧 3. 人工客服

承接上下文进行故障初筛；在线指导可解问题；确需维修则推送报障卡片并审核生成正式工单派发。

👷 4. 工程师

查看待办并认领锁定工单；开展远程/现场排查维修；录入根本原因及处置方案并提交结果。

📚 5. 知识库管理员

日常上传更新 SOP 规范排查手册；审核研判工单解决结果是否具普适沉淀价值，结构化入库反哺 AI。
