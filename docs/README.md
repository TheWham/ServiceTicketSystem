### 五大角色职责与双飞轮流转

| 角色列 | 身份 | 核心业务职责与闭环流转 |
| :--- | :--- | :--- |
| **第 1 列** | **👤 员工** | 发起故障咨询；尝试 AI 排查方案自愈验证；若需维修则补全工单提交；接收完工通知与验收评价打分。 |
| **第 2 列** | **🤖 AI 客服** | 检索知识库并生成自愈排查方案；拦截 80% 常见浅层故障；无法自愈则自动继承会话历史与截图转人工。 |
| **第 3 列** | **🎧 人工客服** | 承接转人工上下文进行二次研判；常规权限问题在线指导化解；确需维修则推送报障卡片并审核生成工单。 |
| **第 4 列** | **👷 工程师** | 查看待办工单并认领；开展现场/远程维修；修复后录入根本原因与解决方案并提交。 |
| **第 5 列** | **📚 知识库管理员** | ① **前置赋能**：日常上传维护标准故障手册；<br>② **经验反哺**：研判已结单方案是否具备普适性，提炼结构化知识入库，**沉淀 RAG 向量库，让 AI 更灵活**。 |

## 💡 答辩核心亮点速记

1. **AI 客服前置自愈过滤**：先排查再提单，阻断 80% 浅层无价值低效单；
2. **人工客服上下文继承把关**：避免大模型幻觉与无用单泛滥，有效工单率达 99% 以上；
3. **知识库双飞轮闭环沉淀**：知识库管理员审核高价值方案，反哺 RAG 向量库，实现“今日解决的疑难，明日转化为 AI 的自愈能力”。
