# 【SYS-002】软件闪退 / 程序无响应

> 所属分类：系统与软件故障

**检索关键词**：闪退, 崩溃, 程序停止工作, 无响应, APPCRASH, 打不开, 白屏

## 现象描述

- 打开某软件后立即闪退，或使用过程中突然崩溃退出。提示「程序已停止工作」「出现了一个问题，导致程序停止正常工作」。常见于：系统更新后、安全软件扫描后、软件版本过旧。

## 常见根因

- ① 软件版本与系统不兼容（旧版软件在新系统上运行）
- ② 依赖组件缺失或损坏（如 .NET Framework、VC++运行库、DirectX）
- ③ 配置文件损坏（用户数据目录下的配置文件）
- ④ 杀毒软件/安全软件拦截
- ⑤ 内存不足（同时运行大型程序）
- ⑥ 软件许可证过期或被吊销

## 员工自助排查

- 步骤1：右键软件图标 → 以管理员身份运行。
- 步骤2：右键软件图标 → 属性 → 兼容性 → 勾选「以兼容模式运行」并选择一个较早的Windows版本。
- 步骤3：彻底关闭软件（任务管理器结束进程），重新打开。
- 步骤4：重启电脑后重试。
- 步骤5：卸载软件 → 从官网下载最新版本重新安装。
- 步骤6：暂时关闭杀毒软件/防火墙后测试，如果正常则添加到白名单。

## IT工程师进阶处理

- 1. 事件查看器（eventvwr.msc）→ Windows日志 → 应用程序，查找崩溃事件（事件ID 1000）。
- 2. 安装/修复 VC++ 运行库合集（Visual C++ Redistributable All-in-One）。
- 3. 使用 Dependency Walker 或 Process Monitor 分析缺失的DLL/依赖。
- 4. 清理软件用户配置目录（%APPDATA% 和 %LOCALAPPDATA%），注意先备份。
- 5. 创建新的Windows用户账户测试，判断是否为当前用户配置文件损坏。
- 6. 如为公司购买的商业软件，联系供应商技术支持。
